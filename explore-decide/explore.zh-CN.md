# 当前边界外探索

[英文](./explore.md) | [简体中文](./explore.zh-CN.md)

> 定位：用于判断什么时候以及怎样重新打开当前边界的活动机制。它不是第七维。

探索回答：**当前可区分或已表示边界什么时候已经不足以支持当前目的，边界外可能缺少什么类型的候选，什么时候值得为进一步探索付出成本，以及应怎样重新打开边界？**

六个维度描述当前活动中不能互相替代的方面。探索开始于：**当前边界本身是否足够**成为了问题。

## 1. “边界外”指什么

世界仍然只是认知边界。探索不声称系统能够枚举“世界之外有什么”，也不把未知变成一个等待取回的隐藏列表。

这里的“当前边界外”，指当前活动所使用的可区分范围、已区分范围、候选空间、问题框定或模型中，尚未得到充分表示的内容。

至少区分：

1. **已知结构内部的值未知**：对象、变量、类别或关系已经形成，但具体值或状态不知道；
2. **候选空间不完备**：真正相关的变量、对象类型、边界、参与者、机制、尺度、取得方式、验证方式或问题框定可能尚未生成；
3. **当前不可取得内容**：某些内容可能重要，但当前感知、语言、工具、接口、权限、资源或协作者还不能提供可调用的区分路径。

因此：

`值未知 ≠ 候选缺失 ≠ 当前不可取得`

`未进入表示 ≠ 不存在 ≠ 不可能`

`当前边界存在缺口 ≠ 已经知道缺失结构是什么`

探索主要处理第二、第三类情况；当第一类未知会实质改变决定时，取得这个值本身也可以成为探索的一部分。

## 2. 当前边界可能不足的信号

不能因为“永远还可能存在更多信息”就持续重新打开边界。只有当当前闭合可能已经不能支持当前目的时，重开才具有现实意义。

典型信号包括：

- 反例或无法归类的剩余项持续出现；
- 预测、解释、协调或干预反复失败；
- 特殊例外增长速度超过当前结构能够吸收的速度；
- 重要结果持续变化，但当前模型中没有对应变量；
- 持续分歧无法还原为已经知道的事实差异或价值冲突；
- 一个原本假定可迁移的结构在新情境中失效；
- 新参与者、工具、传感器、接口、权限或数据源让以前不可区分的内容变得可取得；
- 环境、依赖、时间尺度、权限、价值或风险发生实质变化；
- 高影响决定对某个尚未解决的假设高度敏感；
- 系统正在失去恢复、退出或生成替代方案的能力。

这些是**重新打开的信号**，不是某个替代方案已经正确的证明。

`当前结构出现张力 ≠ 某个替代结构已经正确`

`出现一次意外 ≠ 整个框架必须废弃`

相称的处理可能只是缩小主张范围、缩短有效期、取得一个有区分力的观察、重新打开一个局部区分，或者重新打开更大的问题框定。

## 3. 现在是否值得探索

探索会消耗时间、注意力、计算、金钱、协调能力，有时还会直接产生现实风险。仅仅存在未知，不能形成无限探索义务。

判断现在是否探索，至少考虑：

| 考量 | 问题 |
| --- | --- |
| **决策敏感性** | 一个合理的缺失区分是否可能实质改变当前选择、承诺、授权或完成判断？ |
| **区分价值** | 当前是否存在能够有效区分重要竞争框定或候选的观察 / 探测？ |
| **成本** | 探索需要多少时间、注意力、计算、金钱、协调和机会成本？ |
| **风险 / 不可逆性** | 探索本身是否可能造成损害、锁定、信息暴露、权利影响或不可逆效果？ |
| **紧迫性** | 推迟当前决定或行动会损失什么？ |
| **现在行动的可逆性** | 当前路径能否安全试行并在之后修订，还是一旦行动就会关闭重要未来选项？ |
| **未来选择价值** | 探索是否能够保留或创造实质有用的未来选择？ |
| **当前充分性** | 即使当前边界原则上不完整，它对当前目的是否已经足够？ |

这些考量不要求统一成一个普遍数值目标。不同领域可以使用阈值、侧约束、部分排序、解释型判断或规定型规则。

可能的处置包括：

`保持当前边界`

`进行局部探测`

`重新打开某个区分或假设`

`重新打开更大的问题框定 / 候选空间`

`暂缓探索，但保存未知及其触发条件`

`因为当前没有充分理由或不安全而停止探索`

一次探索转换本身可以需要[资格](../six-dimensions/qualification.zh-CN.md)。这不会使“探索资格”成为新的基础维度。

## 4. 生成替代候选时避免循环准入

当前表示不能要求所有挑战都先完整翻译成自己的词汇，才允许挑战具有意义。

候选生成可以包括：

- 不同的对象边界；
- 不同的分类或本体；
- 缺失的参与者或利益相关者；
- 不同的时间尺度；
- 不同的因果机制；
- 不同的证据来源或取得接口；
- 竞争性问题框定；
- 不同的价值框定或约束集合；
- 不同的执行路径或制度安排。

在挑战阶段：

`挑战准入 ≠ 语义迁移`

一个竞争框定即使还不能与当前体系完整映射，也可以通过不同观察、预测、失败解释或实践结果暴露当前体系的盲区。

只有当替代方案准备被集成、联邦协作、迁移采用或在当前系统中运行时，才需要完成相应语义映射。

## 5. 探索的目标是提高区分力，不只是积累

更多数据只有在改变“当前可以负责任地区分什么”时才真正有用。

一个好的探测问题是：

> 哪个观察、比较、实验、互动或有限干预，最能够区分当前仍然重要的竞争候选？

探索动作可以包括：

- 获取独立来源；
- 更换测量或观察接口；
- 询问拥有不同局部世界的参与者；
- 构造反例；
- 测试边界案例；
- 进行可恢复实验；
- 改变一个相关条件；
- 比较竞争预测；
- 引入新的工具或表示；
- 尝试有边界的替代路径。

探测的成本和影响应与它能够消除的不确定性相称。

`更多观察 ≠ 更有区分力的证据`

`模型置信度提高 ≠ 当前边界已经充分`

`有能力做实验 ≠ 有权做实验`

当探索性干预影响人、权利、共享资源、隐私、安全或不可逆现实状态时，仍然需要独立的价值、资格、权限和能力检查。

## 6. 重新打开的范围与深度

不是每一种张力都需要把所有结构重新打开。

探索可以发生在不同深度：

1. **值取得**：在已经接受的结构中取得缺失值；
2. **局部区分修订**：修改一个类别、边界、关系或假设；
3. **候选空间扩展**：生成当前候选集合中不存在的替代项；
4. **问题重构**：改变对象、谓词、尺度、参与者集合或完成语义；
5. **框架挑战**：允许一个可能不共享当前框架词汇的竞争表示进入比较。

优先使用能够实质解决问题的最浅重开，但不能仅仅为了保护旧结构而强行停留在浅层。

`局部修正已经足够 ≠ 必须全局重开`

`局部修正反复失败 ≠ 继续只修改局部值`

## 7. 暂定闭合与停止探索

探索必须能够停止，否则它会变成无限义务。

在当前目的下，出现以下情况时，可以暂定闭合本轮探索：

- 剩余重要候选已经不太可能实质改变当前决定；
- 当前能力允许范围内，重要竞争候选已经得到足够区分；
- 继续取得信息的实际价值相对于成本已经很低；
- 延迟造成的成本或风险已经超过剩余未知带来的风险；
- 下一步探测过于危险、无权限或不可逆；
- 当前活动可以选择一条可恢复路径，并保存之后修正的能力；
- 不能解决的部分可以被明确携带为未知。

闭合时至少保留：

- 已经探索了什么；
- 哪些候选被排除以及依据；
- 什么仍然未知；
- 当前暂定接受什么边界；
- 什么会触发复核或重新打开；
- 哪些新工具、权限、证据或事件会使继续探索重新变得值得。

因此：

`停止探索 ≠ 已经没有未知`

`暂定闭合 ≠ 永久完整`

`现在不能安全探索 ≠ 缺失候选不存在`

## 8. 常见失败模式

**过早闭合**：因为当前类别方便或已经实现，就把它当成完整边界。

**无限探索**：用“还可能有未知”逃避任何有限承诺。

**模式锁定**：只允许能够用当前本体表达的候选进入。

**新颖偏差**：仅仅因为某个框定新，就认为它更好。

**只积累、不区分**：持续收集数据，却不能更好地区分重要竞争候选。

**不安全探测**：让信息价值替代权限、权利、安全或可逆性。

**虚假不可能**：没有找到路径或候选，就报告它不存在。

**局部失败导致全局重开**：一个有界失配被用来废弃对当前目的仍然有效的结构。

目标不是最大开放，而是**相称的可重新打开性**。

## 9. 与六个维度的关系

探索使用六个维度，但不替代任何一个：

| 维度 | 探索中的问题 |
| --- | --- |
| [区分](../six-dimensions/distinction.zh-CN.md) | 当前什么边界、默认区分或候选空间可能需要重开？ |
| [资格](../six-dimensions/qualification.zh-CN.md) | 是否有充分依据开始探索、停止探索或采用修订后的边界？ |
| [价值](../six-dimensions/value.zh-CN.md) | 哪些未知值得投入资源或承担探索风险？ |
| [能力](../six-dimensions/capability.zh-CN.md) | 当前实际能够取得哪些观察、工具、协作者或干预路径？ |
| [变化](../six-dimensions/change.zh-CN.md) | 边界失效是因为结构正在过渡、不稳定，还是旧依据已经过时？ |
| [他者](../six-dimensions/others.zh-CN.md) | 谁拥有不同信息、框定、激励、权限或探索风险暴露？ |

因此探索不是总维度。它是在“当前边界是否足够”本身成为问题时，协调六维的一种活动。

## 10. 向决策转交与现实反馈

一个最小循环是：

```text
当前边界
    ↓
结构张力 / 新机会 / 实质不确定
    ↓
判断是否有充分依据重新打开
    ↓
生成竞争候选
    ↓
通过有边界探测取得区分性证据
    ↓
修订 / 缩小 / 保持当前边界
    ↓
暂定闭合
    ↓
在接受的边界内决策
    ↓
行动与现实侧反馈
    ↓
保持、重新校准或再次打开
```

如果当前边界对当前目的已经足够，探索可以在生成新候选之前合理停止。

如果后续现实反馈破坏了支持闭合的关键假设，边界可以再次重新打开。

探索的目标不是发现一个最终完整的世界，而是知道：**什么时候当前边界已经足够继续，什么时候还不够，以及怎样改变边界而不假装未知早已成为已知。**
