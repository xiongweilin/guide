# 目的性有限行动者

[English](./purposeful-finite-actor.md) | [简体中文](./purposeful-finite-actor.zh-CN.md)

guide 使用**目的性有限行动者**作为统一的工作主体，但不再把它作为基础起始原语。

[最小推导](../minimal-derivation.zh-CN.md)从最小自指出发，沿主干加入同一性连续、行动能力、有限性和行动相关方向后，才到达这一工作主体。可纠错自我模型属于额外增强，不是行动者的前置条件。

个人、团队、组织、制度、Agent、长期运行服务和技术系统，只要满足本页的工作定义，都可以作为目的性有限行动者分析。

## 1. 工作定义

一个目的性有限行动者以前述最小自指结构为前提，并至少具有：

1. **持续自指**：自身 / 非自身区分能够跨后续转换保持为同一个持续过程的相关区分；
2. **有限生命周期与有界能力**：生命周期，以及至少某些相关感知、表示、计算、资源、接口、控制或恢复能力有界；
3. **局部表示与持久状态**：先前经历能够影响后续转换，同时当前表示保持局部且可错；
4. **行动能力**：至少某些可执行行动会改变现实后续条件；
5. **目的性**：至少某些后续状态、路径、约束或结果对行动具有不同意义。

“目的性”可以来自自我维持、任务、目标、承诺、角色、外部委托、偏好、硬约束或其他方向结构。

这一工作定义不自动意味着主观体验、自由意志、反思自治、道德地位、对他人的权限或完整效用函数。

## 2. 有限性

行动者可能受到感知、数据、语言、分类、表示、时间、注意力、计算、资源、工具、接口、权限、对他者内部状态的认识、未来与反事实认识、现实控制以及纠错 / 恢复 / 退出速度等限制。

这里的有限性指有效能力有界，不要求全部可能内部状态构成数学上的有限集合。

因此完整知识不能作为一般行动前提。

## 3. 生命周期

对行动者 Ai，用 `Li = [bi, di)` 作为其工作生命周期的方便描述，而不是从这一记号“推出”时间。

在 bi 之前，它还没有作为该行动者持续当前过程；在 di 之后，它不再产生新的自身转换。

生命周期内，行动者不断经历：

`Reality → Actor → Reality`

行动者可以变化、学习、退化、锁定或保持稳定。

## 4. 保持的历史与当前边界

目的性有限行动者不要求一开始就具有完整、明确展开的模型。

在框架层，关键是基础的自身 / 非自身差异以及其他先前影响能够被保持，使较早的现实经历影响后续转换。

在更复杂阶段，持久状态可以组织成当前边界、主张、关系、因果假设、候选、目标、承诺等。

基础中的推导顺序是条件依赖顺序，不表示每个行动者都必须在时间中经历一组可分别观察的阶段。

## 5. 目的与选择

目的性只要求某些后续路径对行动具有不同意义，可以表示为接受谓词、偏序、约束集合、目标状态或其他方向结构。

多个目的可能冲突，也不要求存在统一标量效用。

## 6. 能力不是单一属性

至少区分：

- **可能**：现实仍可能如此；
- **可达**：存在到达路径；
- **可控**：行动者能对关键过程施加足够影响；
- **可调用**：当前实际具有所需工具、接口、资源、协作者和权限。

`Possible ≠ Reachable ≠ Controllable ≠ Callable`

能力可以分布在工具、基础设施、组织与他者中，而不只存在于行动者内部。

## 7. 自我模型也可错误

行动者关于自身能力、资源、权限、恢复条件和失败方式的模型，同样只是当前边界的一部分。

`自认为能做到 ≠ 当前可达`

`过去可调用 ≠ 现在仍可调用`

因此现实反馈可以修订自我模型，同时在当前分析所需尺度上仍保持为同一个持续过程。

## 8. 终止与遗留效果

行动者终止时，自身连续过程停止，但既有现实效果不会因此自动消失。

一个人、组织、Agent 或服务可以终止，而其记录、代码、制度、资产、承诺、损伤、部署以及对其他行动者造成的状态变化继续存在于现实中。

`actor termination ≠ effect erasure`
