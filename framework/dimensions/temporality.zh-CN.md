# 时序

[English](./temporality.md) | [简体中文](./temporality.zh-CN.md)

> 定位：本维度是目的性有限行动者描述当前边界时的一个**工作性视角**，不是不可约本体原语。六维共同用于防止重要语义被静默替代；最小推导见 [`../foundations/minimal-derivation.zh-CN.md`](../foundations/minimal-derivation.zh-CN.md)。

时序回答：**什么先后发生、持续多久、以什么速度变化，结构何时有效、过渡或失效？**

时序不只是时间戳。它描述顺序、持续、节奏、期限、稳定性、转变、迟滞、路径依赖与不同时间尺度之间的关系。

## 1. 顺序与持续

同一组对象和关系，如果发生顺序不同，可能产生完全不同的现实结果。

因此至少区分：

- 先后关系；
- 同时与重叠；
- 持续时间；
- 时间窗口；
- 截止条件；
- 周期与频率；
- 延迟；
- 有效期；
- 历史沿革。

`同一状态 ≠ 同一路径`

`当前值相同 ≠ 到达方式相同`

合法终点不能反向证明历史转换合法。

## 2. 稳定、过渡与无稳定结构

在给定范围、时间尺度和扰动条件下，可以区分：

- **稳定**：结构足够持续，可以暂时作为工作对象；
- **过渡**：当前主要处于从一种组织向另一种组织转换的过程；
- **无稳定结构**：当前尺度下没有足够持续的组织可可靠建模。

稳定不表示永恒；过渡不表示终点已知；无稳定结构也不意味着“什么都没有”，而是当前不应强行制造固定分类。

无稳定结构时，相称做法可能是保持未知、缩短判断有效期、提高观察频率或暂缓闭合。

## 3. 多重时间尺度

同一活动可以同时存在：

- 快变量：一次请求、局部行动、短期波动；
- 中变量：工作流、习惯、团队实践、政策；
- 慢变量：身份、核心接口、制度边界、长期关系。

`短期稳定 ≠ 长期稳定`

`长期稳定结构 ≠ 没有快速局部变化`

任何“变化了吗”的判断都应说明尺度。

## 4. 速率相称性

纠错机制形式上存在，并不表示现实中来得及纠错。

可以比较：

`发现 + 判断 + 停止 + 恢复 + 再授权`

与

`错误传播 + 损伤累积 + 锁定`

如果前者已经接近或超过重大不可逆影响形成的时间窗口，系统在结构上可能无法及时纠正。

`存在纠错机制 ≠ 纠错速度足够`

速率相称性不是普遍偏好快或慢，而是比较不同过程的动态是否匹配。

## 5. 迟滞与有效可逆性

进入某状态的路径不一定等于退出时的反向路径：

`进入路径 ≠ 退出路径`

依赖、信任、集中化、信息传播、制度变化和累积损伤都可能形成迟滞。

有效可逆性至少分成：

- **状态可逆**：现实状态能否恢复到可接受条件；
- **控制可逆**：目的性有限行动者能否重新取得停止、修改、接管、迁移或退出能力；
- **认识可逆**：证据、知识、人员、记录、异议通道和验证能力是否仍存在。

形式上的回滚可能只恢复其中一层。

## 6. 路径依赖与锁定

当前可能性不仅由当前状态决定，也受到历史路径影响。

某些行动会：

- 消耗未来选项；
- 增加切换成本；
- 固化分类和制度；
- 形成新的依赖；
- 把临时安排变成默认永久结构；
- 降低未来重新区分和恢复控制的能力。

因此一个系统看似稳定，但如果正在失去退出、替代和恢复能力，它可能已经进入锁定。

## 7. 当前有效性

`历史有效 ≠ 当前仍有效`

事实、范围、依赖、权限、价值、成本、风险、关系或环境发生实质变化时，应重新验证旧结构。

时效有效性不能只看“记录很新”。真正需要检查的是支撑当前主张的依赖是否仍然成立。

重新打开恢复的是候选和选择空间，不会自动给出新答案。
