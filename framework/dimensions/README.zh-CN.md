# 六个工作视角

[English](./README.md) | [简体中文](./README.zh-CN.md)

六维是描述目的性有限行动者**当前边界**的一组工作视角，不是六种终极实体，也没有被证明为不可约、正交或唯一完备。

它们被保留，是因为在实际推理与行动中，静默把这些语义互相替代会造成重要错误。

| 视角 | 核心问题 | 与最小结构的关系 |
| --- | --- | --- |
| [区分](./distinction.zh-CN.md) | 什么能够 / 已经被区分？ | 最接近基础的差异结构 |
| [关系](./relation.zh-CN.md) | 已区分内容怎样连接、依赖和约束？ | 可由结构化元组 / 约束展开 |
| [因果](./causality.zh-CN.md) | 什么干预会改变什么延续？ | 来自行动态的现实延续差异 |
| [时序](./temporality.zh-CN.md) | 什么先后、持续、过期和锁定？ | 来自生命周期与变化顺序 |
| [可能性](./possibility.zh-CN.md) | 现实还可能怎样？ | 来自尚未排除的现实延续 |
| [价值](./value.zh-CN.md) | 什么值得趋近、避免、维持或约束？ | 最弱层来自目的性，强规范层需额外前提 |

典型 non-substitution：

`关系 ≠ 因果`

`先后 ≠ 因果`

`可能 ≠ 可达 ≠ 可控 ≠ 可调用`

`能够做到 ≠ 值得做到`

`当前稳定 ≠ 永久有效`

这些不等式表示“不能未经资格判断静默替代”，不表示两者之间不能建立映射或推导。

最小推导见 [`../../minimal-derivation.zh-CN.md`](../../minimal-derivation.zh-CN.md)。
