# 关系

[English](./relation.md) | [简体中文](./relation.zh-CN.md)

> 定位：本维度是目的性有限行动者描述当前边界时的一个**工作性视角**，不是不可约本体原语。六维共同用于防止重要语义被静默替代；最小推导见 [`../foundations/minimal-derivation.zh-CN.md`](../foundations/minimal-derivation.zh-CN.md)。

关系回答：**已经区分出的内容怎样连接、组成、依赖、约束和相互影响？**

关系不限于“人与人”。对象、变量、组织、角色、资源、接口、规则、网络节点、身份和制度都可以形成关系结构。

## 1. 关系不是因果

关系可以表示：

- 组成 / 从属；
- 依赖；
- 空间或网络位置；
- 身份与角色；
- 所有 / 使用 / 委派；
- 信息可见性；
- 权限与义务；
- 相似 / 冲突 / 一致；
- 资源与交换；
- 参与和代表；
- 关联强度。

但：

`存在关系 ≠ 存在因果效应`

`相关 ≠ 因果`

因果需要额外的干预、机制、对照或反事实依据。

## 2. 关联强度与一致 / 冲突

在人与组织关系中，一个有用的最小表示是：

`关联强度 × 一致 / 冲突`

关联强度问：

> 一方的状态、选择或行动，在多大程度上改变另一方的信息、成本、资源、可能性、价值或现实条件？

一致与冲突必须指明发生在哪个维度，而不是给整段关系贴一个总标签。

参与者可能事实判断一致但价值冲突，也可能价值一致但方法冲突、目标一致但资源竞争、短期一致而长期冲突。

`强关联 ≠ 一致`

`弱关联 ≠ 无关系`

## 3. 局部世界与他者模型

**战略行动者**只是一个分析位置：其判断或行动能够实质改变其他参与者后续的现实、信息、判断条件、成本或可达路径。

`战略行动者 ≠ 主体性 / 体验地位 ≠ 责任资格 ≠ 权限`

不同目的性有限行动者拥有不同当前边界，因此：

`B_i ≠ B_j`

一个系统可以形成关于他者能力、资源、价值、权限、信息、动作候选和判断方式的工作表示，但：

`我对他者的模型 ≠ 他者的真实内部状态`

高阶建模“我认为你认为……”只有在再增加一层会实质改变候选、风险或可判别信息时才值得继续。无法完成无限递归，不妨碍形成有限、可用的关系模型。

## 4. 权力拓扑

关系强度不能代替权力类型。

至少保持：

- **定义权**：塑造问题边界、候选空间、标准或议程；
- **判断权**：判断什么依据已经充分；
- **决定权**：把判断转成承诺、资源配置或具有约束力的选择。

在需要时还应单独表示执行、验证、资源、信息、退出、停止、复核和重新打开等控制位置。

`正式角色 ≠ 实际控制`

`决定权 ≠ 定义候选集合的权力`

`在当前规则下拥有权力 ≠ 修改规则的权力`

当同一参与者或同一故障域同时控制多个本应用来互相检查的位置时，应显式看到这种集中。

## 5. 集体、组织与网络

利益一致不会自动产生集体行动：

`利益一致 ≠ 协调完成 ≠ 持续集体能力`

当内部联盟、激励、权限或信息差异会改变结果时，组织不能被当成放大的个人。

`组织正式目标 ≠ 实际内部激励`

`正式权力 ≠ 实际内部控制`

`很多有能力的个人 ≠ 有能力的集体`

两两关系之和也不能穷尽网络结构。网络位置会改变信息取得、机会、议价权、依赖、扩散、暴露、退出和可达路径。

身份至少可以分成：

`自我身份 ≠ 他者分类 ≠ 制度承认地位`

这些位置可以同时影响价值、权限和可能性。

## 6. 行为、信号与证据

`行为 ≠ 信号 ≠ 证据结论`

同一个报价、沉默、延迟、拒绝、合作或声明，可以没有被取得，可以被不同观察者形成不同区分，也可以支持多个竞争解释。

因此沉默不能默认等于同意、拒绝、无知或策略。

解释失败时，应区分问题发生在现实输入、材料取得、区分、关系建模、证据强度、因果解释，还是更上层的战略局势表示。

## 7. 战略与反身性

战略互动并不预设存在一个已经完整定义的“真博弈”。目的性有限行动者还可能不知道：

- 哪些行动者重要；
- 哪些行动可行；
- 什么信息对谁可见；
- 对方怎样区分和判断；
- 哪个时间尺度相关；
- 当前互动是否被正确框定。

形式博弈、优化器和模拟器只是下游工具。不能因为求解器要求字段完整，就用伪精确填满现实未知。

关系系统还可能反身：

`模型 → 判断 → 行动 → 现实改变 → 他者适应 → 关系再次改变`

公开预测、指标、激励、制度规则和暴露策略都可能改变被建模者。

## 8. 形式表示与异质定向

形成联合战略表示，不表示参与者共享价值或目标：

`联合战略表示 ≠ 共享价值或目标`

`结果可比较 ≠ 参与者共享同一价值尺度`

收益、效用、排序和成本都是建模选择。形式最优、均衡、战略优势或总收益本身都不能产生权限或正当性。

## 9. 权限、承认与正当性

多人活动至少分开：

- **正式权力**：当前制度和范围下谁拥有决定权；
- **承认**：谁在何种范围把某个身份、承诺或权限作为协调依据；
- **正当性**：该权限、规则或承认是否具有充分规范基础。

`策略优势 ≠ 正式权力 ≠ 承认 ≠ 正当性`

承认是关系事实，不是全局布尔值；广泛承认也不自动建立规范正当性。

## 10. 制度与元权力

制度可以提供问题框定、程序、权限、代表、承诺、转交、复核、申诉、退出、重新协商和重开机制。

但制度也会再生产自身：

`制度 → 激励 / 约束 → 行动者适应 → 资源与能力分布 → 未来议价权 → 制度再生产`

`制度持续 ≠ 制度仍被规范正当化`

`存在名义退出 ≠ 现实中有真实退出路径`

还应保持：

`决定权 ≠ 议程设置权`

`在给定选项中选择 ≠ 定义选项集合`

当这些结构会改变参与者的可能性空间时，关系维度必须能够表示它们，但不需要预设一个普遍政治或组织理论。
