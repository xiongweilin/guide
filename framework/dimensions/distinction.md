# Distinction

[English](./distinction.md) | [简体中文](./distinction.zh-CN.md)

Distinction asks: **under current conditions, what can become distinguishable, what has been distinguished, and what remains outside the current representation?**

It describes how a finite system forms callable differences, objects, and classifications from reality. It does not claim that these boundaries are the final structure of reality.

## 1. Basic structure

```text
reality
→ distinguishable range
→ acquire / form differences
→ distinguished range
→ current representation
```

The distinguishable range is constrained by sensing, language, tools, interfaces, permissions, resources, collaborators, and existing capability. The distinguished range can be incomplete and can contain incorrect distinctions.

Therefore keep distinct:

`current representation ≠ distinguished range ≠ distinguishable range ≠ reality`

A finite system does not have sufficient grounds to treat the boundary of its distinguishable range as the boundary of reality.

Once formed, distinctions can in turn change tools, interfaces, capability, and relations:

`distinguishable_range_t → distinguished_range_t → tools / interfaces / relations change → distinguishable_range_t+1`

`not currently distinguished != nonexistent != impossible`

## 2. Default distinctions

Language, culture, education, interfaces, institutions, historical decisions, existing models, and personal experience preinstall many categories and boundaries.

A default distinction means only "immediately callable now." It does not establish that:

- the boundary comes from reality itself;
- the classification is valid for the current problem;
- competing distinctions do not exist;
- the current distinction should remain forever.

Many persistent errors are not wrong answers but default distinctions that were never treated as reopenable.

## 3. Questions arise from distinctions

A sentence being askable proves only that a question candidate has been formed.

Before answering, inspect:

- whether the object boundary is clear;
- whether the predicate applies to that object;
- whether multiple actors, scales, or processes have been collapsed into one object;
- which default distinctions and assumptions were silently imported;
- whether the distinguished range was mistaken for the whole distinguishable range;
- whether the question survives a different distinction.

Therefore:

`question can be asked != question framing is sufficient`

When framing materially changes scope, authority, irreversibility, or completion semantics, it should pass a sufficiency judgment before downstream action.

## 4. Acquisition errors and distinction errors

At minimum separate:

- signal not acquired;
- signal acquired but the difference was formed incorrectly;
- difference formed but classification boundary wrong;
- relation organized incorrectly;
- causal explanation wrong;
- time scale wrong;
- important variables, participants, candidates, or values absent;
- structure valid only in a local scope.

Revision therefore includes not only changing field values but reopening objects, classifications, relations, problem framings, and candidate spaces.

## 5. Unknowns and structural tension

At minimum separate:

- an unknown value inside an already formed structure;
- relevant structure, candidate, or acquisition path not yet formed.

Persistent residuals, counterexamples, boundary failures, cross-context mismatch, or accumulating exceptions can signal that the current distinctions are insufficient.

But:

`current distinction insufficient != correct replacement already known`

A proportionate response may be to narrow scope, weaken the claim, retain unknown, obtain a more discriminating observation, or enter exploration.

## 6. Distinctions across finite systems

Different finite systems can face the same reality while having different:

- sensing and data;
- distinguishable ranges;
- distinguished ranges;
- language and classifications;
- problem structures;
- callable evidence.

Thus "we see the same thing" cannot be established only by using the same words. Coordination may require exchanging facts, forming shared distinctions, or retaining different distinctions while still coordinating action.

## 7. Relation to the other dimensions

Distinction answers only "what differences have been formed." It does not automatically establish:

- [Relation](./relation.md): how the differences connect;
- [Causality](./causality.md): what changes what;
- [Temporality](./temporality.md): order, duration, and change scale;
- [Possibility](./possibility.md): what else may happen;
- [Value](./value.md): what is worth pursuing.

`candidate distinguished != candidate sufficient`

`current classification usable != classification permanently valid`

`my distinctions != distinctions others must accept`
