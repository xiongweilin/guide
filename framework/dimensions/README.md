# Six working lenses

[English](./README.md) | [简体中文](./README.zh-CN.md)

The six dimensions are working lenses on a purposeful finite actor's **current boundary**. They are not six ultimate entities and have not been proved irreducible, orthogonal, unique, or complete.

They are retained because silently substituting these meanings for one another creates material errors in reasoning and action.

| Lens | Core question | Relation to minimal structure |
| --- | --- | --- |
| [Distinction](./distinction.md) | What can be / has been distinguished? | Closest to basic difference structure |
| [Relation](./relation.md) | How do distinguished items connect, depend, and constrain? | Can unfold from structured tuples / constraints |
| [Causality](./causality.md) | Which interventions change which continuations? | Comes from action-sensitive continuation differences |
| [Temporality](./temporality.md) | What precedes, persists, expires, or locks in? | Comes from lifecycle and order of change |
| [Possibility](./possibility.md) | How may reality still continue? | Comes from unexcluded real continuations |
| [Value](./value.md) | What is approached, avoided, maintained, or constrained? | Weakest layer comes from purpose; stronger normativity needs extra premises |

Typical non-substitution:

`relation ≠ causality`

`sequence ≠ causality`

`possible ≠ reachable ≠ controllable ≠ callable`

`can do ≠ worth doing`

`currently stable ≠ permanently valid`

These mean “must not be silently substituted without qualification”, not that no mapping or derivation can exist.
