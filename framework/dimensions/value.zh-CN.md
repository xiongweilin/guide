# 价值

[English](./value.md) | [简体中文](./value.zh-CN.md)

> 定位：本维度是目的性有限行动者描述当前边界时的一个**工作性视角**，不是不可约本体原语。六维共同用于防止重要语义被静默替代；最小推导见 [`../../minimal-derivation.zh-CN.md`](../../minimal-derivation.zh-CN.md)。

价值回答：**什么值得追求、避免、维持、承诺或拒绝？**

事实描述“是什么”；价值提供方向。知道现实怎样，并不能自动推出应该走向哪里。

## 1. 外界规范与内在规范

`外界规范 ↔ 内在规范`

- **外界规范**：家庭、文化、教育、法律、制度、角色、组织、市场、群体和关系带来的要求或期待；
- **内在规范**：体验、偏好、身份、反思、主动选择与承诺形成的方向。

外界规范可以被长期内化；内在规范也会随经验和反思改变。

因此至少区分：

- 来源；
- 主体是否识别来源；
- 是否只是习惯、压力或调节机制；
- 是否经过反思认同；
- 是否形成持续承诺；
- 是否有资格约束他人；
- 是否需要公共正当性。

`我认为这是自己的价值 ≠ 它与外界影响无关`

## 2. 四个分析层次

至少保持：

`描述 / 功能 ≠ 体验 ≠ 反思承诺 ≠ 公共规范`

它们不是必须依次经过的发展序列。

### 描述 / 功能

后果差异只说明状态不同；系统相关性说明某种差异会改变状态、资源、关系或可达路径；调节极性说明系统形成趋近、回避、维持、恢复或搜索方向。

`调节极性 ≠ 主观体验 ≠ 规范结论`

### 体验

在把某对象作为具有正负体验的主体处理之前，需要相称的经验地位依据。

自我维护、奖励/损失、目标表征、复杂行为、自我模型、语言自述、学习和适应都可以成为证据，但任何单项都不能自动证明主体经验地位。

经验地位可以保持`未知`或`有争议`。严重且不可恢复的福利风险可以因为不确定性进入决策，但不能被报告成主体性已经得到证明。

### 反思承诺

一阶定向可以来自身体、体验、习惯、教导、关系、制度、战略互动或外部任务。

反思认领把这些来源、后果和冲突重新作为判断对象，并进行认领、修订、暂存或拒绝。

个体价值承诺可以组织后续行动，同时接受现实代价和可修订性。

`可修订 ≠ 没有承诺`

`形成承诺 ≠ 永久免于修订`

### 公共规范

个体价值不会自动产生对他人的权限。

当选择影响他人、权利、共享资源、第三方或制度时，还需要公共规范、程序、权限、代表、申诉和正当性等额外结构。

`规范相关事实 ≠ 规范结论`

## 3. 规范地位与权利

至少保持：

`有偏好 ≠ 有利益 ≠ 受到影响 ≠ 有道德地位 ≠ 有程序地位 ≠ 有决定权 ≠ 有否决权 ≠ 有权限`

重要权利主张应尽量说明：

- 权利主体；
- 受保护利益或自由；
- 被约束或承担义务的一方；
- 依据与范围；
- 救济、承认或执行保障。

`权利来源 ≠ 权利正当化 ≠ 权利承认 ≠ 权利执行`

guide 不选择一个终极道德理论，只要求会改变决定的规范冲突保持可见。

## 4. 价值冲突与公共决定

价值冲突不必压成一个统一数值尺度。它可能表现为：

- 可比较权衡；
- 阈值或侧约束；
- 优先级冲突；
- 部分可比或不可比；
- 所有路径都损害重要价值的悲剧性冲突。

允许：

`价值 A 有充分依据 + 价值 B 有充分依据 + 实质冲突 + 当前没有充分的共同尺度`

多人活动中还应保持：

`个人偏好 ≠ 聚合偏好 ≠ 集体价值 ≠ 正当决定`

多数票、求和、排序、市场价格或福利度量可以是工具，但不能静默成为完整公共正当化。

`规范真理主张 ≠ 同意 ≠ 公共可辩护性 ≠ 程序正当性 ≠ 权限`

## 5. 来源与有效性

价值可以来自身体、体验、照护、关系、教育、制度、激励、习惯、路径依赖、损失、创伤、模仿、战略互动、反思认领或拒绝。

`解释来源 ≠ 证明无效`

`来源天然 ≠ 规范正当`

`来源社会化 ≠ 价值虚假`

`个人认同 ≠ 对他人的约束力`

`社会普遍接受 ≠ 自动正当`

## 6. 操纵、胁迫与真实退出

判断外部影响时，不只问“价值是否受社会影响”，而要检查影响结构：

- 系统性欺骗或信息控制；
- 威胁、惩罚或资源控制；
- 是否阻断替代信息、关系或退出；
- 是否利用依赖、脆弱性或权力不对称；
- 压力解除后主体是否仍反思认领该方向。

发现操纵或胁迫，只会削弱把表面承诺视为自由稳定价值的充分性；它不会自动告诉系统主体“真正应该想什么”。

名义退出不等于真实退出。真实退出依赖资源、安全、身份、关系、知识、时间和制度条件。

## 7. 承诺与重新打开

价值承诺不是永久冻结。

以下情况可以支持重新打开：

- 体验、一阶定向与反思承诺长期冲突；
- 多个承诺无法共同维持；
- 关键事实基础被否决；
- 实现价值持续产生重大外部损失；
- 身体、关系、环境或身份条件变化；
- 发现胁迫、操纵、严重依赖或没有真实退出。

重新打开不表示存在一个等待发现的“真实价值”，只表示旧依据不足以自动继续。

## 8. 与其他维度

价值依赖区分出的对象、关系、后果和参与者，但不能被事实、能力、因果效应或多数偏好替代。

`能够做到 ≠ 值得做到`

`某结果概率高 ≠ 应该追求`

`战略优势 ≠ 正当性`

`反思承诺 ≠ 对他人的权限`

价值进入行动仍要经过充分性判断、决策和行动链。
