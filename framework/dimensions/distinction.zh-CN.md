# 区分

[English](./distinction.md) | [简体中文](./distinction.zh-CN.md)

区分回答：**当前条件下什么能够成为可区分内容，什么已经被区分，什么仍在当前表示之外？**

它描述有限系统怎样从现实形成可调用的差异、对象和分类，而不是宣称这些边界就是现实本身的终极结构。

## 1. 基本结构

```text
现实
→ 可区分范围
→ 获取 / 形成差异
→ 已区分范围
→ 当前表示
```

可区分范围受感知、语言、工具、接口、权限、资源、协作者和已有能力限制。已区分范围可以不完整，也可以包含错误区分。

区分形成之后又可能改变工具、接口、能力和关系，所以这是反馈结构：

`可区分范围_t → 已区分范围_t → 工具 / 接口 / 关系变化 → 可区分范围_t+1`

`当前没有区分出来 ≠ 不存在 ≠ 不可能`

## 2. 默认区分

语言、文化、教育、接口、制度、历史决定、既有模型和个人经验会预装大量分类与边界。

默认区分只表示“现在容易调用”，不表示：

- 边界来自现实本身；
- 分类对当前问题有效；
- 竞争区分不存在；
- 当前区分应永久维持。

很多持续性错误不是答案错，而是问题所依赖的默认区分从未被重新打开。

## 3. 问题来自区分

一句话能够被提出，只证明出现了一个问题候选。

在回答之前，可以检查：

- 对象边界是否清楚；
- 谓词是否适用于该对象；
- 是否把多个主体、尺度或过程压成一个对象；
- 哪些默认区分和前提被静默带入；
- 当前已区分范围是否被误当成全部可区分范围；
- 换一种区分后，原问题是否仍成立。

因此：

`能够提出问题 ≠ 问题已经充分成立`

问题框定会实质改变范围、权限、不可逆性或完成语义时，应先经过充分性判断。

## 4. 获取错误与区分错误

至少分开：

- 信号没有被取得；
- 信号已取得，但没有形成正确差异；
- 差异形成，但分类边界错误；
- 关系组织错误；
- 因果解释错误；
- 时间尺度错误；
- 重要变量、参与者、候选或价值没有出现；
- 结构只在局部范围成立。

所以修订不只包括“修改字段值”，还包括重新打开对象、分类、关系、问题框定和候选空间。

## 5. 未知与结构张力

至少区分：

- 已形成结构中的值未知；
- 相关结构、候选或取得方式尚未形成。

持续的剩余项、反例、边界失败、跨情境失配或例外累积，可以构成当前区分不足的信号。

但：

`当前区分不足 ≠ 已经知道正确替代`

相称响应可能只是缩小范围、降低主张强度、保留未知、取得更有区分力的观察，或进入探索。

## 6. 多个有限系统的区分

不同有限系统可以面对同一现实，却拥有不同的：

- 感知与数据；
- 可区分范围；
- 已区分范围；
- 语言和分类；
- 问题结构；
- 可调用证据。

因此“看到同一件事”不能只按词语一致判断。协调有时需要交换事实，有时需要先形成共同区分；也可能最终保留不同区分而仍能协调行动。

## 7. 与其他维度

区分只负责“什么被形成成可识别差异”。它不自动建立：

- [关系](./relation.zh-CN.md)：差异之间怎样连接；
- [因果](./causality.zh-CN.md)：什么改变什么；
- [时序](./temporality.zh-CN.md)：先后、持续与变化尺度；
- [可能性](./possibility.zh-CN.md)：还可能怎样；
- [价值](./value.zh-CN.md)：什么值得。

`区分出候选 ≠ 候选已经充分`

`当前分类可用 ≠ 当前分类永久有效`

`我的区分 ≠ 他者必须接受的共同结构`
