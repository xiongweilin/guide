# 生命周期：从出现到终止

[English](./lifecycle.md) | [简体中文](./lifecycle.zh-CN.md)

生命周期描述一个目的性有限行动者从出现到终止的一般过程。它是框架层的过程结构，不是工程状态机。

[最小推导](./foundations/minimal-derivation.zh-CN.md)中的条件依赖顺序不是生命周期时间线。最小自指及其后续新增条件规定什么结构足以成为工作主体；本文描述的是该主体已经成立之后如何持续经历现实。

## 1. 总体过程

\`\`\`text
出现 / 出生
    ↓
现实作用
    ↓
保持的历史 / 当前自身相关状态
    ↓
形成当前边界 B
    ↓
下一转换的充分性 S(B, P, T)
    ├─ 不足 / 实质不确定 → 认识性转换：探索 / 修订 ─┐
    └─ 足够             → 承诺性转换：选择 / 行动   │
                                               │
                                               ▼
                                              现实
                                               │
                                          效果 / 反馈
                                               │
                             保持 / 修订 / 重新打开
                                               │
                                               └──► 下一循环
    …
    ↓
终止 / 死亡
\`\`\`

一个行动者可以有大量嵌套循环；这里不要求每次活动都严格按线性顺序发生。

## 2. 初始阶段

第一次观察到的行动者状态不要求已经具有完整模型，也不要求把基础推导重新按时间阶段演一遍。

最低要求只是：先前现实经历能够留下与后续自指和转换相关的状态：

\`Reality → 保持的状态 → 后续转换\`

对 guide 的工作行动者而言，这种历史保持建立在基础中已经定义的最小自指结构之上。

稳定对象、关系、因果假设、时间结构、候选、目的和承诺可以随后明确形成，也可以部分保持隐含。

## 3. 当前边界

当前边界 B 是行动者在当前活动中实际可调用的局部表示与认识状态。

它可以不完整、错误、过时，在不同活动中采用不同粒度，并因新工具、权限、关系和经验而改变。

当行动者形成更丰富的自我模型时，该模型也是当前边界的一部分，并可以被修订，而不要求因此失去同一性连续。

当前六个工作视角只是描述 B 的一种展开方式。

## 4. 两类主要转换

### 认识性转换

主要改变行动者知道什么、如何区分或如何框定，包括观察、探测、比较、建立或否决主张、生成候选、重构问题和修订当前边界。

guide 把边界不足时有目的的认识性转换称为**探索**。

### 承诺性转换

主要形成选择、承诺或现实作用方向，包括选择候选、配置自身资源、进入行动路径以及形成将影响后续现实的承诺。

guide 把暂定充分后形成选择的活动称为**决策**。

## 5. 现实作用不是内部状态转换

行动者内部形成选择，并不等于现实已经改变。

框架层只要求保留：

\`选择 / 行动 ≠ 现实效果 ≠ 后续反馈\`

更细的 Decision / Authorization / Execution / Effect / Observation / Outcome 等工程语义位于[工程行动链](../engineering/action-chain.zh-CN.md)。

## 6. 保持、修订与重新打开

反馈后至少有三类结果：

- **保持**：当前边界仍足以支持后续活动；
- **修订**：在现有框架中修改值、关系、范围、依据或自我模型；
- **重新打开**：原暂定闭合本身失去充分性，需要重新探索候选、框定或工作视角。

\`重新打开 ≠ 自动推翻全部历史\`

## 7. 终止

行动者终止时，不再产生新的自身转换。终止原因可以来自自然生命周期、外部停止、解散、资源耗尽、不可恢复故障、目的完成后的退役等。

框架不要求所有终止都可逆，也不把“持续存在”自动作为最高价值。

终止后，既有现实效果可以继续进入其他行动者的生命周期。
