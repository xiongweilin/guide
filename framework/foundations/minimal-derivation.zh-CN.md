# 最小推导

[English](./minimal-derivation.md) | [简体中文](./minimal-derivation.zh-CN.md)

> 目标：不是证明 guide 为终极真理，而是把“哪些结构由前提推出、哪些只能条件推出、哪些只是工作性或工程性选择”分开。

## 1. 起点

设有外部现实 R，以及多个目的性有限行动者 A1, A2, …, An。每个行动者 Ai 只在有限生命周期 Li = [bi, di) 中存在，并具有：

- 有限内部状态空间 Mi；
- 从现实历史到当前内部状态的有限表示映射 qi: HR → Mi；
- 能够影响现实后续条件的行动；
- 至少一种目的、接受条件、硬约束或趋近 / 回避方向。

“目的性”只要求某些后续状态或路径对行动形成不同意义；它不预设自由意志、主观体验、完整效用函数或终极道德理论。

“外部现实”只要求现实能够对行动者提供不由其当前表示自行决定的约束、效果和反馈；不要求先规定现实的终极组成。

## 2. 有限表示推出现实与表示非同一

有限性意味着，在相关现实历史上 qi 一般不是单射。可以存在：

`h1 ≠ h2` 且 `qi(h1) = qi(h2)`。

因此同一当前状态可以与多个不同现实历史相容。由此得到：

`当前表示 ≠ 现实`

定义当前不可区分等价类：

`[h]i = { h' | qi(h') = qi(h) }`

行动者面对的是这个局部等价类，而不是现实的完整复制。

## 3. 区分与未知余量

任何非平凡行动者至少必须能区分某些内部状态、输入或行动，否则所有状态和行动都等价。因此“差异 / 区分”是最难继续删除的结构之一。

若某命题 p 在两个当前不可区分的现实历史上取值不同，而 qi(h1) = qi(h2)，行动者就不能仅凭当前状态同时正确断言 p 或非 p。

所以对一个不把证据不足伪装成知识的行动者，必须允许某种未决状态：

`未决 / 未知余量`

这不要求工程上一定存在名为 `Unknown` 的对象；它首先是有限表示的结构结果。

## 4. 生命周期推出顺序与变化

有限生命周期至少具有先后：`bi < t1 < t2 < di`。

若行动者能够保持或改变状态，就有 `mi(t1) → mi(t2)`。因此某种顺序、持续和变化结构不可删除。

但这不能证明“时序”必须是独立本体原语；它可以表示为关系 `x ≺ y`。

`时序语义必要 ≠ 时序是不可约本体范畴`

## 5. 行动推出行动敏感的现实延续

设 `Cont(h, a)` 表示在历史 h 下采取行动 a 后仍可出现的现实延续。

如果所有行动都满足 `Cont(h, a1) = Cont(h, a2)`，这些行动对现实没有控制意义。

因此“行动者”至少要求存在某些 a1、a2，使：

`Cont(h, a1) ≠ Cont(h, a2)`

这给出最弱意义的因果 / 干预结构：不同可执行行动可以改变现实延续空间。它不要求预先接受更强的因果形而上学。

## 6. 六维不是最小原语集

- **可能性**可以理解为当前尚未排除的现实延续集合；
- **关系**可以理解为已区分项之间的结构约束或元组；
- **时序**可以理解为事件或状态之间的顺序关系；
- **因果**可以理解为干预对延续结构的差异。

因此六个工作视角并不是最小表示原语集。它们的意义在于防止实践中把不同问题静默压成同一种语义。

## 7. 目的性给出方向，但不自动给出规范伦理

目的性假设要求至少存在某种行动相关方向，例如接受谓词 `AcceptP(h, a)`、偏序、约束集合或目标状态。

这足以得到最弱意义的“价值 / 方向 / 约束”，但不能自动推出：

- 主观体验；
- 反思承诺；
- 道德地位；
- 公共正当性；
- 对他人的权限。

`功能方向性 ≠ 完整规范理论`

## 8. 充分性的条件推导

设当前边界为 B，目的为 P，准备进入下一转换 T。

如果行动者既可能继续取得区分，也可能进入承诺性行动，那么其策略必然隐含一个边界 `S(B, P, T)`，区分“当前仍需探索 / 修订”和“当前可以进入下一转换”。

即使系统内部没有 `sufficient=true` 字段，只要它有时继续获取信息、有时停止并行动，就已经行为上实现了某种 sufficiency boundary。

`有限认识 + 目的 + 可选择探索或行动 → 局部充分性问题`

但“系统事实上进入了转换”只建立**操作触发条件已满足**，不能自动建立“它有充分理由这样做”。

`operational trigger ≠ warranted sufficiency`

## 9. 探索与决策的条件推导

当转换主要修改当前边界、取得区分或扩大候选时，可以归为**认识性转换**；guide 将其称为探索。

当转换形成选择、承诺或现实作用路径时，可以归为**承诺性转换**；guide 将其称为决策并进入行动。

因此探索 / 决策不是本体原语，而是目的性有限行动者在充分性边界两侧常见的两类活动。

## 10. 反馈与重新打开

现实效果和后续观察可能与当前边界不一致。若系统要求具有纠错能力，则关键依据失效、预测失败、效果偏离或新结构出现时，必须允许 `Bt → Bt+1`，并在必要时重新开放原来已经暂定闭合的结构。

`有限认识 + 现实反馈 + 纠错要求 → 可重新打开性`

如果行动者不具有纠错能力，则这一结论不成立；它只是一个不可修订的目的性有限行动者。

## 11. 多行动者结构

不同目的性有限行动者具有不同映射 qi，因此一般 `Bi ≠ Bj`，即使它们处于同一个现实。

一个行动者还可以通过现实改变另一个行动者的后续条件：

`Ai → Reality → Aj`

于是共享现实中自然出现不同局部表示、互相建模、协调与冲突、战略适应和反身反馈。

但授权、权利、正当性和治理程序仍需要额外制度或规范前提，不能由多行动者存在本身推出。

## 12. 终止不删除现实效果

行动者在 di 后不再继续自身过程，但此前留下的效果已经成为现实的一部分，可以继续影响其他行动者。

`行动者终止 ≠ 其现实效果消失`

这适用于人、组织、Agent、服务、模型实例和其他有界行动系统。

## 13. 当前最小结果

目前能够保持的最小工作结构是：

`外部现实 + 目的性有限行动者 + 局部区分 + 受约束变化 + 双向作用`

对具有探索、选择和纠错能力的行动者，再得到：

`局部充分性 + 反馈修订`

由此可展开：

`Reality ↔ Actor → Boundary → Sufficiency → Transition → Reality → Feedback → Revision`

## 14. 没有被证明的东西

本推导**没有**证明：

- 现实最终由“行动者、边界、反馈”等实体构成；
- 六维是不可约或唯一的；
- 所有行动者都必须学习、反思或纠错；
- 所有价值都可从功能目的推出；
- Decision、Authorization、Effect、Outcome 等工程角色是宇宙结构；
- guide 是唯一能够描述这些过程的框架。

这些更强主张需要额外前提、竞争理论比较和现实检验。
