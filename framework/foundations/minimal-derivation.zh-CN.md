# 最小推导

[English](./minimal-derivation.md) | [简体中文](./minimal-derivation.zh-CN.md)

> 目标：先确定最小充分自指结构，再一次只增加一个会实质改变结构的必要条件。以下顺序表示条件依赖，不表示现实系统必然按该顺序发生，也不以符号压缩代替证明。

## 1. 起点：最小自指

guide 只从三个条件开始：

1. **外部约束**：存在不被当前表示穷尽、并持续约束当前表示的现实。
2. **反身区分**：进行区分的过程将自身与非自身现实区分开来。
3. **保持与再进入**：这一自身 / 非自身差异进入并保持于当前表示，并能够再次成为产生该差异的区分过程的区分对象。

这三个条件共同足以形成本文采用的最弱自指：区分过程保持一个包含自身的差异，并能够再次对这一已保持差异进行区分。

这里的“自身”只指区分中指向“维持这一持续区分过程”的一侧。它还不等于人、意识主体、自主 Agent、道德主体或稳定身份。

最小自指本身**不能**建立：

- 跨后续转换的同一性连续；
- 可修订的自我模型；
- 对现实的行动；
- 有限性；
- 目的；
- 充分性、决策或学习。

## 2. 增加同一性连续：持续自身

只增加一个条件：

> 后续反身区分能够把此前保持的自身一侧与当前维持区分的过程视为同一个持续过程。

没有这个条件，再进入可以反复发生，但各次出现的“自身”仍可能彼此无关。

加入这一条件后，得到最弱意义的**持续自身**：不是不可改变的实体，而是在变化中保持自指连续。

这种连续要求转换之间存在某种先后结构，但这不能证明“时序”是不可约本体原语。

## 3. 可选增强支路：增加现实侧可修订性

从持续自身出发，只增加一个条件：

> 现实侧失配能够改变已经保持的自身相关内容，同时不消除使这些内容仍指向同一持续过程的连续性。

此时得到 guide 所需的最弱**可纠错自我模型**：系统可以关于自己出错，也可以随后修订这一表示。

它仍不推出主观体验、内省透明性或完整自知。

这一层是增强支路，不是“成为行动者”的前置条件。持续自身可以具有行动能力，同时仍然不可纠错。

## 4. 增加改变现实的行动：行动者

回到从持续自身出发的主干，只增加一个条件：

> 持续系统至少存在某些可执行转换，能够改变后续现实条件。

此时才得到 guide 工作意义上的**行动者**。

内部转换、尝试行动、现实效果和后续观察仍是不同结构。行动能力要求现实延续对实际行动敏感，而不是内部状态仅仅标记“行动发生了”。

## 5. 增加有限性：有限行动者

只增加一个条件：

> 行动者在生命周期，以及某些相关感知、表示、计算、资源、接口、控制、纠错或恢复能力上存在边界。

有限性不要求把全部可能内部状态假设成数学上的有限集合。真正需要的是：当前有效能力有界，不能被预设为能够穷尽现实。

当相关现实区分超过当前表示能力时，不同现实条件可以与同一当前表示相容，由此产生未决认识余量。

\`当前表示 ≠ 现实\` 只是压缩写法；真正起作用的是更强的前提：现实存在不由当前表示穷尽或自行决定的约束。

有限行动者最终会终止。若它此前已经改变现实，则行动者终止不等于其已经留下的现实效果消失。

## 6. 增加行动相关方向：目的性有限行动者

只增加一个条件：

> 某些后续状态、路径、约束或结果对行动具有不同意义。

此时有限行动者才具有**目的性**。

目的可以表现为接受条件、偏序、约束、目标、趋近 / 回避方向、角色、承诺或其他行动相关方向。

这足以建立功能性方向，但不能建立完整规范理论、道德地位、公共正当性、对他人的权限、自由意志或主观体验。

到这里，guide 才得到统一的工作主体：**目的性有限行动者**。

## 7. 增加探索 / 承诺选择：局部充分性

只增加一个条件：

> 对某个下一转换，行动者既可以继续取得或修订区分，也可以进入具有承诺的转换。

此时其策略在实践中必须区分“继续探究”与“进入下一转换”的情况。

guide 把这一边界所要求的依据称为**局部充分性**。

\`operational trigger ≠ warranted sufficiency\`

转换事实上发生，只能证明触发发生了。若行动者主张“现在有充分依据继续”，相关依据、未知、失效条件、风险与可恢复性才进入充分性问题。

## 8. 探索与承诺是派生活动类型

在充分性边界已经成立的条件下：

- 主要改变当前边界、区分、证据或候选空间的转换，是**认识性转换**；guide 把其中有目的的活动称为探索；
- 主要形成选择、承诺或现实作用路径的转换，是**承诺性转换**；guide 把形成选择的活动称为决策。

它们是工作性活动类型，不是本体原语。

## 9. 增加纠错要求：反馈修订与重新打开

只增加一个条件：

> 实质性的现实侧失效必须能够改变当前边界。

此时预测失败、效果偏离、新区分出现、关键假设失效或现实条件变化，可以引发修订，或者重新打开此前的暂定闭合。

没有纠错要求时，现实仍可以反驳行动者，但行动者本身可以保持不可修订。

## 10. 增加其他行动者：多行动者结构

在同一现实中再加入一个或多个目的性有限行动者。

不同的行动者不必共享感知、表示、历史、目的、资源或权限，因此即使受同一外部现实约束，也可以拥有不同局部边界。

一个行动者还可以通过现实改变另一个行动者的后续条件。

由此才出现互相建模、协调、冲突、战略适应与反身反馈。

授权、权利、正当性和治理不能从“存在多个行动者”本身推出；它们仍需要额外制度或规范前提。

## 11. 六个工作视角不是基础原语

区分、关系、因果、时序、可能性和价值仍然是描述当前边界的有用工作视角。

上述推导不要求把它们当作现实的六个不可约组成。它们的实践作用是防止具有实质差异的问题被静默替换成同一种语义。

## 12. 分层结果

条件依赖可以压缩为：

\`\`\`text
外部约束
+ 反身区分
+ 保持与再进入
= 最小自指

+ 同一性连续
= 持续自身

├─ + 现实侧可修订
│  = 可纠错自我模型
│
└─ + 改变现实的行动
   = 行动者

   + 生命周期 / 能力有界
   = 有限行动者

   + 行动相关方向
   = 目的性有限行动者

+ 探索 / 承诺选择
= 局部充分性问题

+ 纠错要求
= 反馈修订 / 重新打开

+ 其他行动者
= 多行动者结构
\`\`\`

这里的等号只表示“此前结构加上本层新增条件，足以形成所命名的工作框架”，不是数学同一，也不是形式证明。

## 13. 没有被证明的东西

本推导**没有**证明：

- 现实最终由自指系统、行动者、边界或反馈组成；
- 所有自指系统都有意识、目的或行动能力；
- 所有行动者都具有纠错、反思、道德性或自治；
- 六个工作视角不可约或唯一；
- 所有价值都来自功能性目的；
- 多行动者存在会自动推出某种治理规则；
- Decision、Authorization、Effect、Outcome 等工程角色是宇宙结构；
- guide 是唯一能够描述这些过程的框架。

更强主张仍需要额外前提、竞争解释与现实检验。
