# 通用方法论原则：问题导向、相关性与相称检验

[English](principles.md) | 简体中文

## 1. 定位与必要性的范围

guide 面向理解、认识、评价、选择与行动的不同问题。其目标是减少影响判断的混淆和遗漏，而不是以单一理论解释所有对象。

- **通用**是跨领域可调用，不是适用条件完全相同。
- **必要**是针对具体问题：如果遗漏某项区分、关系或证据可能实质改变结论，就应处理；不能据此宣称任何固定清单在逻辑上最小、不可约或完备。
- **相称**指依据主张性质、影响、风险、可逆性和可取得证据调整论证深度；并非所有低风险判断都需要完整审计。

## 2. 四条贯穿规则

1. **问题锚定：**明确问题、对象、范围、时间尺度及要得出的主张；区分一般规律、群体与个案。
2. **相关性检验：**探索差异与系统联系，但检验它们能否影响理解、推理、评价或行动；不因存在差异就要求全部列出。
3. **判准匹配：**说明区分依据、关系性质和主张类型，使用相应成立标准；推理有效性、前提真实性、经验效果及规范正当性不能互相替代。
4. **反例修正：**检验有力的竞争解释、反证、边界案例和失效条件；需要时缩界、降低强度、合并、重开或舍弃旧结构。

这些规则在分析过程中循环使用，不是末尾才执行的检查表。

## 3. 主张类型与判准

| 主张 | 主要检验 | 不能自动推出 |
| --- | --- | --- |
| 概念／分类 | 定义、对象、反例、区分的工作价值 | 现实因果事实 |
| 形式／逻辑 | 前提、有效推导、证明、反模型 | 前提在现实为真 |
| 经验描述 | 可靠观察、测量、来源和适用总体 | 因果或未来必然性 |
| 经验预测 | 事前对象、时间、基线及后续独立结果 | 因果与行动权限 |
| 解释／因果 | 竞争解释、机制、对照、识别及迁移假设 | 可调用的干预路径 |
| 干预／行动效果 | 实际条件、对照或相称归因、外部验证 | 规范正当性或授权 |
| 价值／规范 | 价值理由、权利、义务、程序、授权和取舍 | 可由事实或多数认同直接决定 |

观察不等于无误事实，证据支持不等于确定为真；推理有效不保证前提真实。不同类型可能交叉，一个复杂主张应分别检验其经验、形式和规范部分。

## 4. 使用边界

[九组关键区分](distinctions.zh-CN.md)和[系统视角](systems.zh-CN.md)是非穷尽资源，可以互相修正，不要求逐项全部使用。系统关系不自动构成因果；自指、反馈、涌现和复杂机制均须按条件确认。

涉及特定下一转换时，可调用[充分性](../methods/sufficiency.zh-CN.md)；涉及现实执行时，再处理授权、能力、执行、外部验证和恢复。形式证明、测试、受控实验及长期现实效果是不同证据层级，不得静默升级。
