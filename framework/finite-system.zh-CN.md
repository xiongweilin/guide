# 有限系统：框架的使用者

[English](./finite-system.md) | [简体中文](./finite-system.zh-CN.md)

本框架的使用者是**有限系统**。

个人、家庭、团队、组织、制度、Agent 与技术系统都可以作为有限系统分析。这里的“有限”不是缺陷判断，而是一个事实条件：没有任何使用者能够无成本地完整观察现实、穷尽所有候选、完成无限推理，并同时控制所有相关因果条件。

## 1. 有限性

有限系统至少受到以下限制：

- 感知与数据来源有限；
- 语言、分类和表示能力有限；
- 时间、注意力与计算有限；
- 资源和工具有限；
- 权限和可调用接口有限；
- 对他者内部状态的认识有限；
- 对未来和反事实的认识有限；
- 对现实因果过程的控制有限；
- 纠错、恢复和退出速度有限。

因此有限系统必须能够**暂定闭合**。否则“现实永远还有未知”会把行动变成无限探索。

这正是充分性算子存在的原因：它不要求知识完整，只要求当前边界对当前目的和下一次转换足够。

## 2. 当前边界

有限系统在某项活动中形成一个当前边界 (B)。它由六个维度描述：

```text
B = {区分, 关系, 因果, 时序, 可能性, 价值}
```

这里不是说有限系统必须拥有六张表或六个模块，而是说重要活动不能把这些语义静默压成一个总状态。

当前边界还应附带**认识状态**。认识状态不是第七维，而是有限系统对自己当前主张的来源与可信程度的元数据，例如：

- 来源与溯源；
- 观察 / 推导 / 假设 / 他者陈述；
- 未验证 / 有支持 / 有争议 / 已反驳 / 未知；
- 适用范围与时间；
- 关键假设；
- 复核或失效条件。

`当前相信 X ≠ X 已成为现实事实`

`高模型置信度 ≠ 权威事实`

## 3. 可能、可达、可控与可调用

有限系统需要把四件事分开：

- **可能**：某个状态仍属于当前可能性空间；
- **可达**：存在从当前条件到该状态的可行路径；
- **可控**：有限系统能够对相关因果变量施加足够控制；
- **可调用**：当前确实能取得所需工具、接口、资源、协作者、权限和恢复路径。

因此：

`Possible(X) ≠ Reachable(X) ≠ Controllable(X) ≠ Callable(X)`

这组差别属于可能性、因果与有限系统接口之间的横切结构，不另立“能力”维度。

当系统还没有发现路径时，合理状态可能是`未知`，而不是`不能`。只有在明确范围和充分依据下，才能形成当前“不能”的判断。

## 4. 自身、辅助与借势

可调用路径可以通过不同方式形成：

- **自身路径**：主要依靠自身身体、知识、技能和直接资源；
- **辅助路径**：借助工具、设备、AI、专业服务、制度接口或他者；
- **借势路径**：利用环境、规则、网络、激励、自动化或既有趋势，使系统不承担主要因果过程。

现代系统的大量能力分布在关系、基础设施、制度和工具中，而不是只存在于主体内部。

因此：

`系统拥有技能 ≠ 当前存在可调用路径`

`因果效应存在 ≠ 当前有干预接口`

`存在干预接口 ≠ 当前有权限使用`

## 5. 自我模型与校准

有限系统会维护关于自身资源、工具、接口、权限、协作者、失败方式和可达路径的工作模型。这个模型同样可能过时。

`自认为能做到 ≠ 当前现实中可达`

`过去能做到 ≠ 现在仍能做到`

提供方、工具、权限、资源、协作者、环境、恢复条件或制度结构变化时，系统需要重新校准。

新形成的区分也可能发现原来没有看见的路径；新的工具、关系和接口甚至可能创造此前不存在的路径。

## 6. 责任与权限

有限系统可以同时承担多个角色，但必须区分：

- 定义问题、候选或规则；
- 判断当前依据是否充分；
- 形成决定；
- 授权；
- 执行；
- 观察；
- 验证；
- 恢复；
- 重新打开。

一个角色存在，不会自动创造另一个角色的权限。

`能够判断 ≠ 有权决定`

`有权决定 ≠ 自动获得底层资源权限`

`能够执行 ≠ 值得执行`

责任也应与当时实际可取得的知识、权限、能力和因果贡献相称。

## 7. 机动性

高水平的行动能力不只是“能完成当前方案”，还包括：

- 能生成替代方案；
- 能切换工具与依赖；
- 能停止影响；
- 能恢复控制；
- 能承担转换成本；
- 能重建前置条件和授权；
- 能解释发生了什么；
- 能保留异议、证据和重新区分的能力。

最深的锁定不是失去某个当前选项，而是同时失去重新发现替代方案和恢复控制的能力。

有限系统因此不仅要问“现在能不能做”，还要问“这样做以后是否还保有修订自己的能力”。
