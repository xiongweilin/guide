# Activities: exploration and decision

[English](./README.md) | [简体中文](./README.zh-CN.md)

Exploration and decision are not ontological dimensions. They are two activity classes that commonly appear around the sufficiency boundary of a purposeful finite actor.

- [Exploration](./exploration.md): epistemic transitions when the current boundary is insufficient or materially uncertain for the next transition;
- [Decision](./decision.md): forming a choice or commitment when the current boundary is provisionally sufficient for the current purpose and next transition.

`S(B, P, T) = insufficient → explore / revise`

`S(B, P, T) = sufficient → decide / act`

This is a working classification. Concrete systems may use finer or different activity structures.
