# 活动：探索与决策

[English](./README.md) | [简体中文](./README.zh-CN.md)

探索和决策不是本体维度，而是目的性有限行动者围绕充分性边界出现的两类活动。

- [探索](./exploration.zh-CN.md)：当前边界不足或存在会实质改变下一转换的不确定性时，进行认识性转换；
- [决策](./decision.zh-CN.md)：当前边界对当前目的和下一转换暂定足够时，形成选择或承诺。

`S(B, P, T) = 不足 → 探索 / 修订`

`S(B, P, T) = 足够 → 决策 / 行动`

这只是工作分类。具体系统也可以有更细或不同的活动结构。
