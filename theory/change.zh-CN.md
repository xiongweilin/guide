# 变化

[English](./change.md) | [简体中文](./change.zh-CN.md)

变化回答：**当前面对的是可持续结构、转换过程，还是尚无稳定结构？**

时间本身不是这里的核心；核心是结构在相关尺度上如何持续、失效和重组。

## 基本结构

`稳定 / 过渡 / 无稳定结构`

### 稳定

在给定时间尺度、范围和扰动条件下，某种关系或组织足够持续，可以暂时作为工作对象。

稳定不表示永恒，也不表示底层没有变化。它只表示当前尺度上存在可重复、可依赖的结构。

### 过渡

当前形态主要是从一种组织向另一种组织转换的过程。

此时比固定分类更重要的是：

- 方向；
- 速度；
- 转换条件；
- 路径；
- 不可逆性；
- 哪些旧结构正在失效；
- 哪些新结构正在形成。

处于过渡不表示终点已经知道。

### 无稳定结构

在当前尺度上没有足够持续的组织可供可靠建模。

这时强行固定对象、分类或规则，可能制造一个实际上并不存在的稳定实体。合理做法可能是保留 unknown、缩短判断有效期、提高观察频率或暂缓闭合。

## 不同时间尺度

同一活动可以同时包含：

- 快变量：一次请求、局部行动、短期波动；
- 中变量：工作流、习惯、团队实践、政策；
- 慢变量：身份、核心接口、制度边界、长期关系。

一个结构在短期稳定，不表示长期稳定；一个长期稳定结构也可以包含大量快速局部变化。

因此“变化了吗”必须先明确尺度。

## Closure、revalidation 与 reopening

有限系统需要临时闭合：

`开放 → 收敛 → 暂定闭合 → 持续 → 条件变化 → review / reopening`

历史上有效，不表示现在仍有效。

当证据、范围、依赖、环境、authority、价值、身份、成本或风险发生实质变化时，应重新验证旧结构。

Reopening 不会自动给出新答案，它只恢复候选和选择空间。

## 路径依赖与 lock-in

变化并不只取决于当前状态，还取决于如何到达这里。

某些行动会：

- 消耗未来选项；
- 增加切换成本；
- 形成依赖；
- 固化分类和制度；
- 让临时安排变成默认永久结构。

因此需要同时观察当前状态和未来机动能力。

系统看似稳定，但如果正在失去退出、替代、恢复和重新区分的能力，它可能已经进入 lock-in。

## 与其他维度的边界

[区分](./distinction.zh-CN.md)决定当前把什么看成结构，[资格](./qualification.zh-CN.md)决定何时保持或重新打开，[价值](./value.zh-CN.md)可能随经历修订，[能力](./capability.zh-CN.md)决定能否改变路径，[他者](./others.zh-CN.md)则会使多个变化过程相互耦合。
