# 变化

[英文](./change.md) | [简体中文](./change.zh-CN.md)

> 灵感来源：稳定与不稳定的冲突。

变化回答：**当前面对的是可持续结构、转换过程，还是尚无稳定结构？**

时间本身不是这里的核心；核心是结构在相关尺度上如何持续、失效和重组。

## 基本结构

`稳定 / 过渡 / 无稳定结构`

### 稳定

在给定时间尺度、范围和扰动条件下，某种关系或组织足够持续，可以暂时作为工作对象。

稳定不表示永恒，也不表示底层没有变化。它只表示当前尺度上存在可重复、可依赖的结构。

### 过渡

当前形态主要是从一种组织向另一种组织转换的过程。

此时比固定分类更重要的是：

- 方向；
- 速度；
- 转换条件；
- 路径；
- 不可逆性；
- 哪些旧结构正在失效；
- 哪些新结构正在形成。

处于过渡不表示终点已经知道。

### 无稳定结构

在当前尺度上没有足够持续的组织可供可靠建模。

这时强行固定对象、分类或规则，可能制造一个实际上并不存在的稳定实体。合理做法可能是保留未知、缩短判断有效期、提高观察频率或暂缓闭合。

## 不同时间尺度

同一活动可以同时包含：

- 快变量：一次请求、局部行动、短期波动；
- 中变量：工作流、习惯、团队实践、政策；
- 慢变量：身份、核心接口、制度边界、长期关系。

一个结构在短期稳定，不表示长期稳定；一个长期稳定结构也可以包含大量快速局部变化。

因此“变化了吗”必须先明确尺度。

## 速率相称性

多个过程可以以不同速度同时发生。一个纠错机制即使形式上存在，如果它比损伤形成或锁定的速度更慢，现实中仍可能来不及发挥作用。

可以比较：

`发现 + 判断 + 停止 + 恢复 + 再授权`

与

`错误传播 + 损伤累积 + 锁定`

如果纠错总耗时已经接近或超过重大不可逆影响形成的时间窗口，那么系统可能在结构上无法及时纠正。

`存在纠错机制 ≠ 纠错速度足够`

速率相称性不是普遍偏好“更慢”或“更快”，而是判断响应过程的动态是否足以应对当前变化过程。

## 迟滞与有效可逆性

进入某个状态的路径，不一定等于退出该状态时的反向路径：

`进入路径 ≠ 退出路径`

依赖、信任、集中化、信息传播、制度变化和累积损伤都可能具有迟滞：恢复所需条件可能与形成该状态时的条件完全不同。

因此有效可逆性至少区分：

- **状态可逆**：相关现实状态能否恢复到可接受条件；
- **控制可逆**：参与者能否重新取得停止、修改、接管、迁移或退出的能力；
- **认识可逆**：理解和修订当前处境所需的证据、知识、人员、记录、异议通道和验证能力是否仍存在。

形式上的回滚可能只恢复其中一层，而其他层仍不可逆。最深的锁定不是失去一个当前选项，而是连重新发现替代方案或恢复控制的能力也一起失去。

## 闭合、重新验证与 重新打开

有限系统需要临时闭合：

`开放 → 收敛 → 暂定闭合 → 持续 → 条件变化 → 复核 / 重新打开`

历史上有效，不表示现在仍有效。

当证据、范围、依赖、环境、权限、价值、身份、成本或风险发生实质变化时，应重新验证旧结构。

重新打开不会自动给出新答案，它只恢复候选和选择空间。

## 路径依赖与锁定

变化并不只取决于当前状态，还取决于如何到达这里。

某些行动会：

- 消耗未来选项；
- 增加切换成本；
- 形成依赖；
- 固化分类和制度；
- 让临时安排变成默认永久结构。

因此需要同时观察当前状态和未来机动能力。

系统看似稳定，但如果正在失去退出、替代、恢复和重新区分的能力，它可能已经进入锁定。

## 与其他维度的边界

[区分](./distinction.zh-CN.md)决定当前把什么看成结构，[资格](./qualification.zh-CN.md)决定何时保持或重新打开，[价值](./value.zh-CN.md)可能随经历修订，[能力](./capability.zh-CN.md)决定能否改变路径，[他者](./others.zh-CN.md)则会使多个变化过程相互耦合。
