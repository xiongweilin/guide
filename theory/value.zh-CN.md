# 价值

[英文](./value.md) | [简体中文](./value.zh-CN.md)

> 灵感来源：想做与应该做的冲突。

价值回答：**什么值得追求、避免、维持、承诺或拒绝？**

事实描述“是什么”；价值提供方向。知道世界怎样，并不能自动推出应该走向哪里。

价值形成不能被压成从事实、奖励、偏好或体验直接跳到规范结论的一步。不同层次需要不同的证据与资格。

## 基本张力

`外界规范 ↔ 内在规范`

- **外界规范**：来自家庭、文化、教育、法律、制度、角色、组织、市场、群体和关系的要求或期待。
- **内在规范**：来自体验、偏好、身份、反思、主动选择和承诺的方向。

这不是简单二分。外界规范可以被长期内化，以至于主体不再感知其来源；内在规范也会随经验和反思改变。

因此至少要区分：

- 规范来自哪里；
- 主体是否识别其来源；
- 是否只是习惯、压力或调节机制；
- 是否经过反思认同；
- 是否形成了持续承诺；
- 是否有资格约束他人；
- 是否需要公共正当性。

“我觉得这是我的价值”本身，不足以证明它与外界规范无关。

## 价值形成：四个层次

可以用一条不可静默替代的发生链展开：

`后果差异 → 系统相关性 → 调节极性 → 经验地位门 → 经验极性 → 一阶定向 → 反思认领 → 个体价值承诺`

每个箭头都引入新的问题，不能自动跨越。

### 描述 / 功能层

**后果差异**只表示不同状态、关系或行动会带来可区分的后续现实，不说明哪一侧更好。

**系统相关性**表示某种差异会改变当前系统的状态、能力、关系、资源、可达路径、维护或恢复条件。相关性必须说明系统边界、时间尺度和适用条件。

**调节极性**表示这些差异进入反馈、比较、控制、判断或行动组织后，形成相对稳定但可修订的趋近、回避、维持、恢复、抑制或搜索方向。

因此，一个系统可以通过习惯、奖励、控制目标或生理机制趋近或回避某些状态，但这本身不能自动建立主观体验或规范价值。

`调节极性 ≠ 体验 ≠ 规范结论`

### 体验层

在把某个状态作为正面或负面**体验**讨论之前，需要通过**经验地位门**：必须有相称的领域理由，把当前对象作为具有自身体验的主体处理。

自我维护、奖励/损失、目标表征、复杂行为、自我模型、语言自述、学习、适应或战略能力都可以成为证据，但任何一项都不能单独自动越过这道门。

主体经验地位可以保持为 `未知` 或 `有争议`。如果误判可能造成严重且不可恢复的福利损失，这种不确定性可以进入行动风险，但不能因此被报告成主体性已经得到证明。

通过经验地位门之后，经验极性也不等于效用函数，更不要求所有体验都进入一个统一数值尺度。

### 反思层

**一阶定向**是实际进入判断或行动的趋近、回避、维持、取得、停止、保护或承诺方向。它可以来自身体、体验、习惯、教导、关系、制度、战略互动或外部任务。

**反思认领**把既有定向、体验、来源、后果和冲突重新作为判断对象，并进行认领、修订、暂存或拒绝。

**个体价值承诺**是在当前条件下形成的认领，它能够组织后续判断和行动，同时接受相称的维护条件、现实代价与可修订性。

`可修订 ≠ 没有承诺`

`形成承诺 ≠ 免于修订`

### 公共规范层

个体价值不会自动产生对他人的权限。

当选择影响他人、权利、共享资源、第三方或制度时，还需要公共规范、决策程序、权限、代表、申诉与正当性等额外判断。

`具有规范相关性的事实 ≠ 规范结论`

痛苦、福利、恐惧、依恋、尊严受损或强烈个人承诺都可能是重要事实材料，但不能单独完成公共规范判断。

## 规范规范地位与权利主张

不是每一种偏好或受影响利益都自动占据相同规范位置。多人问题中至少应区分：

`有偏好 ≠ 有利益 ≠ 受到影响 ≠ 有道德地位 ≠ 有程序地位 ≠ 有决定权 ≠ 有否决权 ≠ 有权限`

这些位置可以重叠，但不能从一个位置静默继承另一个位置。

权利主张应保留足够结构，说明究竟在主张什么，而不是把“权利”当作一个不可再分的标签。根据领域不同，可以包括：

- 权利主体；
- 被保护的对象、利益、自由、身份或机会；
- 义务承担者或受到约束的一方；
- 来源与 正当化依据；
- 范围、条件和优先级；
- 是否以及怎样可以被优先覆盖；
- 救济、复核或 申诉；
- 承认与现实执行保障。

至少保持：

`权利来源 ≠ 权利正当化 ≠ 权利承认 ≠ 权利执行保障`

guide 不尝试从一个终极道德基础推导所有权利；它只要求，当权利及其冲突会实质影响决定时，相应依据必须保持可见。

## 规范冲突、聚合与公共正当化

价值冲突不能全部压成一种通用权衡。根据具体问题，应保留例如：

- 可比较价值之间的普通权衡；
- 阈值冲突，即超过某个界限后优先级发生变化；
- 侧约束，即不能被自由补偿交换的边界；
- 角色、承诺或主张之间的优先级冲突；
- 部分可比性，即只有部分比较已经取得资格；
- 不可比性，即当前没有建立共同排序；
- 悲剧性冲突，即所有可用方案都会违反重要价值或主张。

因此，一个合法的当前状态可以是：

`价值 A 已取得资格 + 价值 B 已取得资格 + 存在实质冲突 + 当前没有取得资格的共同尺度`

不能被标量优化器自动闭合，不代表这个状态本身就是失败。

多人活动中还应保持：

`个人偏好 ≠ 聚合偏好 ≠ 集体价值 ≠ 正当决定`

聚合可以有用，但聚合规则自身也带有假设、排除、信息要求和分配后果。多数票、求和、排序、市场价格或福利度量都不能静默成为完整公共规范判断。

因此，对多人具有约束力的决定可能需要一个**公共正当化结构**：谁受到影响、谁具有规范地位、哪些主张和权利进入、什么信息可接受、什么不能交换、采用什么程序、谁决定，以及保留什么复核、申诉或 退出。

`规范真理主张 ≠ 同意 ≠ 公共可辩护性 ≠ 程序正当性 ≠ 权限`

guide 不选择一个最终的正义、福利、自由、公平、权利或正当性理论。它的任务是让冲突结构保持足够可检查，使领域规范理论或制度能够接入，而不会被混同成事实、偏好、收益或权力。

当外部理论以规范含义使用“能力”时，还应保持术语边界：

`guide 的因果能力 ≠ 规范能力 / 实质自由`

## 来源与有效性

价值可以来自身体、体验、照护与关系、教育、制度、激励、习惯、路径依赖、损失、创伤、模仿、战略互动、反思认领或拒绝。

价值来源追踪用于理解承诺如何形成，不是为了寻找一个隐藏的“真正原因”。

至少保持：

`解释来源 ≠ 证明无效`

`来源天然 ≠ 规范正当`

`来源社会化 ≠ 价值虚假`

`个人认同 ≠ 对他人的约束力`

`社会普遍接受 ≠ 自动具有正当性`

来源、认同、有效性和公共约束力需要分别判断。

## 操纵、胁迫与真实退出

判断外部影响时，关键问题不只是“这个价值是否受社会影响”。多数价值本来就有社会与历史来源。

更应检查影响结构：

- 是否存在系统性欺骗或信息控制；
- 是否通过威胁、惩罚或资源控制压缩真实选择；
- 是否阻断替代信息、关系或退出路径；
- 是否利用依赖、脆弱性或权力不对称；
- 外部压力解除后，主体是否仍反思认领该定向。

发现操纵或胁迫，不会自动告诉系统“主体真正应该想什么”；它只会削弱把当前表面承诺直接视为自由、稳定价值的资格。

名义上存在退出选项，不等于具有真实退出能力。退出可能依赖资源、安全、身份、关系、知识、时间和制度条件。

## 多元价值与可比较性

多个价值可以进入同一个问题，而不必被压成统一尺度。

`结果可比较 ≠ 共享同一价值尺度`

有些场景适合使用成本、偏好排序或效用表示；另一些场景需要保留权利边界、不可补偿损失、角色义务、身份性承诺，或者只允许部分可比较。

因此，更稳定的均衡或更高的总收益本身不能完成“应该接受什么”的判断。

## 承诺与重新打开

承诺不是永久冻结价值。

当持续冲突或条件变化实质削弱旧依据时，应重新打开，例如：

- 体验极性、一阶定向与反思认领长期冲突；
- 多个承诺无法共同维持；
- 关键事实基础被实质否决；
- 实现价值持续制造外部成本或未预期损失；
- 身体、关系、环境或身份条件改变；
- 发现胁迫、操纵、严重依赖或缺少真实退出。

重新打开价值判断，不表示存在一个等待被发现的“真实价值”；它只表示旧资格不足以自动继续。

长期坚持不等于永久免审，短期负面体验也不自动使长期承诺失效。

## 与其他维度的边界

- 价值所依赖的对象和规范来源需要先被[区分](./distinction.zh-CN.md)。
- 一个价值进入承诺、规则或行动，需要独立的[资格](./资格.zh-CN.md)。
- “值得做”不表示当前有[能力](./能力.zh-CN.md)做到，真实退出能力也属于能力问题。
- 价值会随经历和结构[变化](./变更.zh-CN.md)。
- 当价值涉及多人时，需要进入[他者](./others.zh-CN.md)中的一致、冲突、战略互动、权限、承认和 正当性。
