# 交互

[English](interaction.md) | [简体中文](interaction.zh-CN.md)

## 使用方法

1. 识别行动者、受影响方、目的、局部边界、资源和权限；共享现实不意味着共享表示或目标。
2. 将消息和行动绑定到指代对象、版本、范围、时间、证据、预期结果，以及请求、报告、决定和承诺的具体含义。
3. 在实质相关时，区分定义、充分性判断、决定、同意、授权、执行、验证与完成。
4. 对每个重要下一转换检查[局部充分性](../framework/sufficiency.zh-CN.md)；耦合行动还要核对相容性、共享依赖与最低可恢复性。
5. 明确交接、验收条件、义务、确认或拒绝、有效期、升级路径，以及受控修正和退出方式。
6. 依据[评估](evaluation.zh-CN.md)验证独立的现实效果；当含义、权限、约束或结果失配时修订或重新打开。

## 人与人交互

- **问题：** 人们即使理解相同词语，也可能在事实、解释、激励、价值、优先级或正当权限上存在分歧。
- **方法：** 区分证据、问题框定、因果、时序、资源、利益、权利和决定程序的争议；识别谁可定义候选、判断充分性、决定、同意或重新打开。
- **结果：** 可追溯的协议或明确保留的分歧，记录范围、受影响方、承诺、验收条件及复核或退出权利。
- **示例：** “发布已获批准”可能表示技术就绪、产品验收或法务签核；应明确哪个主体在什么条件下批准哪个版本。
- **边界：** 谈判成功、投票或战略优势，本身不证明公平、权限或规范正当性。

## 人与 AI 交互

- **问题：** 人的指令不能完整表达预期结果，AI 对词语、工具、权限和成功标准的理解可能与人不同。
- **方法：** 明确目标、作用边界、委托权限、禁止效果、可观测后置条件，以及需要澄清或人工批准的情形。
- **结果：** 有界委托：允许的探索与行动、显式保留的未知、可靠核验，以及在缺少权限或充分依据时交还或受控停止。
- **示例：** “把功能上线”不自动授权合并任意分支或部署生产；应绑定版本、环境、测试、审批者与现实回读。
- **边界：** AI 的高置信回答、一次审批点击或 API 调用成功，都不自动等于知情同意、有效授权、现实效果或任务完成。

## AI 与 AI 交互

- **问题：** 任务名称一致的 Agent 仍可能拥有不同局部边界、Schema 版本、假设、能力、资源和约束。
- **方法：** 交换任务与对象身份、接口契约、状态版本、证据、共享资源归属、权限、预期效果与失败处置；协调并发写入和期限。
- **结果：** 相容的局部转换、可检查的交接及独立验证的组合结果，而不要求完整共享表示。
- **示例：** 两个编程 Agent 可能各自通过单元测试，却实现不兼容的 API Schema；Schema 归属、集成测试、合并守卫与恢复属于共同转换。
- **边界：** 局部充分不自动建立组合充分、线性加速、共同目的或全局最优。

## 通用交互记录

- **语境：** 行动者身份与角色、受影响方、目的、范围、时间、边界版本、证据来源和权限。
- **含义：** 对象指代、消息类型、相关区分、解释、假设、替代项及未解决的失配。
- **承诺：** 提案与接受、决定主体、授权、下一转换及充分性依据、时限、失效时间和验收条件。
- **反馈：** 执行尝试、实际效果、独立观察、验证、剩余义务、恢复状态和重开条件。

## 交互形式机制案例

- **范围：** 保留 C03、C06、C07、C08、C09、C10 六个有限多行动者形式机制；它们不证明现实同意、经验预测或正当权限。


## C03 Gale–Shapley 稳定婚姻：提议权影响匹配

- 前提：男性 A: X>Y；B: Y>X。女性 X: B>A；Y: A>B。每人仅匹配一人，偏好完整严格，使用延迟接受。
- 预期：男性提议得到 A-X、B-Y；女性提议得到 B-X、A-Y。两种匹配均无阻挡对。
- 条件变化：交换提议方会改变此例结果；只改变同一方内部的提议调度顺序，不改变标准算法在固定偏好下的最终匹配。
- 禁止外推：算法稳定性不证明现实生活中的偏好不变、同意或关系质量。

## C06 公共物品博弈：激励外部性

- 前提：四人各有 1 单位，可贡献全部或零；总贡献乘 2 后平分，每人保留未贡献余额。
- 预期：每增加自己 1 单位贡献，个人公共返还只增加 0.5，因此“不贡献”对任何其他人的选择都严格占优。全部贡献每人得 2，总计 8；全部不贡献每人得 1，总计 4。
- 条件变化：改变公共回报倍数或制度激励后，必须重新推导边际收益。
- 禁止外推：私人占优不证明集体结果最优。

## C07 VCG 单物品拍卖：真实报价的条件性激励

- 前提：单物品、私人估值、准线性效用、标准第二价格拍卖；估值为 A=10、B=8、C=5，均真实报价。
- 预期：A 获胜，支付 8，净效用 2。标准机制下，真实报价是弱占优策略，不要求每种虚报都严格更差。
- 条件变化：若存在串通、外部性或违反拍卖机制假设，不能将弱占优结论无条件迁移。
- 禁止外推：宣称报价真实不等于独立验证私人估值真实。

## C08 拥堵博弈：个体均衡非全局最优

- 前提：两人各选择 A 或 B 道路；A 的通行时间等于 A 上人数，B 的通行时间恒为 2.5。
- 预期：两人都走 A 时各耗时 2，单独改走 B 会耗时 2.5，因此 (A,A) 为严格纳什均衡，总耗时 4；一人走 A、一人走 B 的总耗时为 1+2.5=3.5，是四种路由配置的社会总成本最小值。
- 条件变化：改变通行成本函数或人数后，必须重算均衡与社会最优。
- 禁止外推：局部合理不自动建立组合充分或总体最优。

## C09 Nash 议价：依赖分歧点

- 前提：总可分配收益为 10，分歧点为 d=(1,3)，效用线性，允许连续分配且满足个人理性。
- 预期：最大化 (x-1)(y-3)，约束 x+y=10，得到唯一 Nash 议价解 (4,6)。
- 条件变化：改变分歧点或效用、可行域时，需要重新计算，不能继续使用 4:6。
- 禁止外推：解的数学定义不证明其满足所有现实中的权利与规范约束。

## C10 联盟博弈 Core：整体稳定性的存在性

- 前提：三人 A、B、C 的单人联盟收益为 0；任意双人联盟为 100；三人联盟为 120。可转移效用，总收益全额分配。
- 预期A：Core 为空。三组双人联盟约束相加要求 2×120≥300，实际不成立。
- 条件变化：三人联盟收益由 120 增至 150 时，Core 非空，且唯一分配为 (50,50,50)。
- 禁止外推：已知每个子联盟可以合作，不等于大联盟存在稳定的分配。
