# 评估

[English](evaluation.md) | [简体中文](evaluation.zh-CN.md)

## 1. 先区分四个问题

- **转换充分性**：当前边界对某目的与下一转换是否已有相称依据；充分不保证未来结论必然正确。
- **判断正确性**：在明确标准、对象与适用条件下，结论能否由可信依据及适用方法支持。
- **预测质量**：事前给出的未来主张，在其时间、总体与条件内，与后续独立取得的结果有多一致。
- **决策正当性**：计算或预测正确，不自动产生价值正当性、同意或执行权限。

```text
充分性 ≠ 结论为真
形式推导正确 ≠ 模型假设适用于现实
预测命中 ≠ 因果效应得到识别
预测校准 ≠ 每个具体预测都会命中
评估分数提高 ≠ 外部目的改善
```

## 2. 判断前选择验证类型

| 类型 | 需要固定的条件 | 相称验证 | 不能推出 |
| --- | --- | --- | --- |
| 形式 / 规则推导 | 公理、收益、偏好、约束、量词、规则版本 | 证明、穷举、反例、独立实现、规则符合性测试 | 对真实场景的经验有效性 |
| 经验事实或解释 | 对象、来源、时间、定义、竞争解释 | 独立来源、可靠测量、交叉核对、保留争议 | 未观察状态必然不存在 |
| 经验预测 | 目标总体、事前时间、预测窗口、结果定义、基线 | 锁定预测后进行外部观察、误差与校准对比 | 因果解释或行动权限 |
| 干预 / 因果预测 | 干预、对照、结果、识别假设、干扰和适用环境 | 相称的实验 / 准实验 / 因果识别与迁移检查 | 仅凭相关性声称因果 |

- **规范性主张**：分别检查事实基础、推理一致性、程序及适用规范；不以单个分数代替正当性。

## 3. 最小可检验主张

```text
claim_id
claim_type: formal | empirical | forecast | causal | normative
target / population / outcome_definition
purpose / scope / applicable_conditions
created_at / evaluation_horizon
boundary_version / evidence_refs / model_or_rule_version
assumptions / competing_explanations / residual_unknowns
claim / prediction / uncertainty_representation
verification_method / independent_source / baseline
observation_status / observed_at / observed_result
error_or_counterexample / disposition / reopen_conditions
```

- **事前冻结**：经验预测必须在验证结果可知之前锁定内容、版本和时间窗口；事后修改应产生新版本，不能覆盖旧记录。
- **结果资格**：结果未到期、来源不可用、对象不匹配、缺少可靠回读时记为待验证 / 未知，不作为命中或失败。
- **模型覆盖**：精确概率只覆盖已定义的结果空间；未列出的竞争候选和范围外情况仍需表示为未知。
- **独立性**：评估者与被评估者共用数据、标签、规则或上游来源时，不得直接视为独立证据。

## 4. 如何比较准确性

- **形式判断**：使用证明、反例或可复核计算检验；前提改变后重新检查适用性，未找到反例不等于证明。

- **经验预测**：事前固定基线、损失函数、总体与样本划分。二元事件可使用 Brier 损失 `(p-y)²`；连续目标可使用 MAE。按需要报告校准、分组表现、覆盖率及不确定性，不重复计权事件。

- 时间序列按时间前后分离训练、调参和测试，避免未来信息泄漏。
- 优先对比简单基线与旧版本，在同一目标总体、同一指标和相同外部结果上比较；不能因为更改评价标准而宣称改进。
- 小样本、选择性披露、分布偏移、参与者适应、结果标签不可靠时，报告限制而不是报出不相称的精确分数。
- 对允许拒答的系统，分别报告覆盖率和已回答样本的质量；拒答不能伪装为预测正确。
- 预测到事件发生，不足以证明自己的干预导致该事件。

## 5. 误差归因与重新打开

- **误差类型**：事实或证据错误、对象 / 问题框定错误、形式推导错误、模型或识别假设错误、时间 / 总体迁移错误、目标 / 评分标准错误、测量错误、真实的随机偏差、其他行动者适应或环境变化。

1. 检查结果是否到期且可独立观察；不能验证时保持未知。
2. 核对事前主张、当前边界、适用范围、来源和模型版本。
3. 依已声明的标准比较；必要时检验反例、替代解释或条件变化。
4. 对可证伪的错误修订对应事实、模型、规则或范围；对随机偏差先累积证据，不凭一次失败草率重构。
5. 保存历史及其当前资格；必要时重新打开探索、充分性评估或决策。重开本身不授予执行权限。

## 6. 多行动者的特别检查

- **战略响应**：表面报价不等于内部偏好；提议权影响匹配；个体与集体目标不等同；均衡不必唯一或公平；公开模型可能改变参与者策略。

- **博弈模型**：记录轮次、信息结构、行动顺序、偏好、效用及关键反事实条件。

## 7. 完成标准与边界

- **形式案例**：能重算预期结果、识别明确反例、区分无解与未找到解，并在关键条件变化时重新判断。
- **经验预测**：存在事前记录、独立结果、固定基线和可重复的误差统计；没有真实结果就不能宣称预测准确性提升。
- **部署与行动**：与[行动链](https://github.com/xiongweilin/aios/blob/main/docs/reference/guide/action-chain.zh-CN.md)中的授权、效果验证和恢复保持分离。
- **效率**：按风险和不可逆程度选择验证深度，避免所有低风险动作都引入复杂持久化。

## 8. 研究提案

- [充分性评分者研究](studies/sufficiency-raters-v1.zh-CN.md)是检验解释型分类可重复性的草案；尚无评分数据，也未预注册。
- [判断收益研究](studies/judgment-benefit-v1.zh-CN.md)拟与等投入的简单清单比较；尚无结果数据，不能据此声称 guide 有独立增益。
- [影响路径](studies/impact-pathway.zh-CN.md)将有界执行证据与尚未测量的总劳动及人的收益主张分开。
