# guide

这组文档讨论一个问题：有限的人和 AI 如何从现实中的差异形成判断，取得继续行动所需的资格，改变现实，并在长期系统中保持纠错、退出和改变方向的能力。

目标只有三个：普通人能理解；工程师能落地；理论和工程语义都最小且充分。

## 阅读顺序

1. [从差异到资格](./从差异到资格.md)：理论主线。差异、区分、结构、判断、资格、收缩、重开和责任。
2. [认识与判断](./认识与判断.md)：有限认识、候选空间、证据、判断和认知闭合。
3. [互动、价值与制度](./互动、价值与制度.md)：多主体、权限、承认、正当性、价值和主体体验边界。
4. [行动、授权与可靠性](./行动、授权与可靠性.md)：从判断到现实效果，覆盖授权、执行、验证、恢复和长期治理。
5. [精确语义](./精确语义.md)：把前述边界落实为 source、state、policy、authorization、provenance、verification、reconciliation、revalidation 和 conformance test。

## 共同原则

一个层面的成立，不能自动成为下一个层面的成立条件：

`观察 ≠ 解释 ≠ 判断 ≠ 决定 ≠ 授权 ≠ 执行 ≠ 现实效果 ≠ 目标完成 ≠ 长期有效`

理论说明“什么条件足以继续”；工程把这些条件拆成可检查的字段、状态、权限、转换和测试。

文档本身不产生事实、权限或执行资格。现实系统中的有效性必须由当前事实、规则、授权和验证决定。
