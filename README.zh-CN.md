[English](README.md) | [简体中文](README.zh-CN.md)

> 一个关于有限系统如何在现实边界内形成当前边界、判断其是否足够、在不足时探索、在足够时决策，并通过行动链接受现实反馈的工作框架。

本仓库不试图给出世界的终极本体，也不把某一种认知模型、优化方法或工程实现当作现实本身。它只要求：有限系统对当前活动形成的边界足够清楚，重要语义不被静默替代，未知不被伪装成已知，并且行动后能够由现实反馈修订。

## 整体结构

```text
现实（外部边界）
    │
    ▼
有限系统
    │
    ▼
当前活动 / 当前目的
    │
    ▼
构造当前边界 B
    │
    ├─ 区分
    ├─ 关系
    ├─ 因果
    ├─ 时序
    ├─ 可能性
    └─ 价值
    │
    ▼
充分性 S(B, purpose, next transition)
    ├─ 不足 / 实质不确定 → 探索 → 修订 B
    └─ 足够             → 决策
                             │
                             ▼
                           行动链
                             │
                             ▼
                            现实
                             │
                         现实侧反馈
                             │
                    保持 / 修订 / 重新打开
```

这里各位置承担不同责任：

- **现实**是外部边界。当前表示、模型、模式、本体、分类或知识图谱都不等于现实本身。
- **有限系统**是框架的使用者。个人、团队、组织、制度、Agent 和技术系统都可以作为有限系统；它们都受到感知、语言、时间、计算、资源、权限和控制能力的限制。
- **六个维度**用于描述当前活动边界：区分、关系、因果、时序、可能性、价值。
- **充分性**是算子，不是第七维。它判断当前边界是否已经足以支持当前目的下的下一次转换。
- **探索与决策**是两种活动，不是维度。边界不足时探索；边界暂时足够时决策。
- **行动链**把决定与现实连接起来，并保存决定、授权、执行、现实效果、观察、验证、结果和重新打开之间的差别。

## 六个维度

六维不是六类对象，也不要求彼此独立、正交或处于同一逻辑层级。它们只是当前框架中不能静默相互替代的六个描述维度。

| 维度 | 核心问题 |
| --- | --- |
| [**区分**](./framework/dimensions/distinction.zh-CN.md) | 什么能够被区分，什么已经被区分，什么仍在当前表示之外？ |
| [**关系**](./framework/dimensions/relation.zh-CN.md) | 已区分内容之间怎样连接、组成、依赖、约束和相互影响？ |
| [**因果**](./framework/dimensions/causality.zh-CN.md) | 什么变化会导致什么变化，什么干预能够改变什么结果？ |
| [**时序**](./framework/dimensions/temporality.zh-CN.md) | 什么先后发生、持续多久、以什么速度变化，结构何时有效或失效？ |
| [**可能性**](./framework/dimensions/possibility.zh-CN.md) | 现实还可能怎样，哪些路径可达、可调用、未知或已被排除？ |
| [**价值**](./framework/dimensions/value.zh-CN.md) | 什么值得追求、避免、维持、承诺或拒绝？ |

典型不可替代关系：

本仓库中的 `A ≠ B` 通常是“不可静默替代”的简写：A 成立本身不足以建立 B，A 也不能未经资格判断直接替代 B。它并不表示 A 到 B 之间不可能存在有效转换、映射或经过资格确认的实现关系。

`当前表示存在某个分类 ≠ 现实只有这种分类`

`存在关系 ≠ 存在因果效应`

`观察到先后 ≠ 已建立因果`

`可能发生 ≠ 当前系统能够让它发生`

`能够做到 ≠ 有权做到 ≠ 值得做到`

`当前稳定 ≠ 永久有效`

`个人偏好 ≠ 集体价值 ≠ 正当的共同决定`

## 充分性算子

[充分性](./framework/sufficiency.zh-CN.md)回答的不是“当前模型是否完整”，而是：

> 对当前目的和下一次转换，当前边界已经足够了吗？

因此充分性是局部、目的相关、时间相关且可重新打开的。它可以通过两种基本机制建立：

- **解释型充分性**：通过对语境、证据、反证、竞争解释、剩余未知和风险的可追责判断形成暂定闭合；
- **规定型充分性**：按照显式、带版本的规则、谓词、阈值、守卫条件、测试或契约检查。

二者可以组合，但不能静默替代。

`边界足够用于下一步 ≠ 边界完整`

`规定规则满足 ≠ 规则当前适用 / 有效 / 有权限`

`解释判断有理由 ≠ 已经存在确定性规则`

## 探索与决策

[探索](./framework/activities/exploration.zh-CN.md)负责在当前边界不足或存在实质不确定时重新打开边界。探索的目标不是无限收集信息，而是提高对重要竞争候选的区分力，并在继续探索的价值不足时能够停止。

[决策](./framework/activities/decision.zh-CN.md)负责在当前边界暂定足够之后形成选择。它允许多个可接受选项、部分排序、不可通约的理由以及显式的选择机制，而不把选择伪装成唯一被逻辑强制推出的结果。

`存在未知 ≠ 必须无限探索`

`多个可接受选项 ≠ 没有理由也可以任意选择`

`不存在唯一最优 ≠ 无法形成可负责决定`

## 行动链

[行动链](./framework/action-chain.zh-CN.md)把框架闭合到现实：

```text
决定
→ 承诺 / 治理依据
→ 授权
→ 执行
→ 现实效果
→ 观察
→ 验证
→ 结果 / 完成判断
→ 保持、修订、恢复或重新打开
```

这些位置不能压成一个“成功”：

`决定 ≠ 授权`

`授权 ≠ 执行`

`执行成功 ≠ 现实效果发生`

`现实效果发生 ≠ 目标完成`

`目标完成 ≠ 长期责任解除`

现实反馈可能只要求更新一个值，也可能要求重新打开关系、因果、时序、可能性、价值、问题框定，甚至当前六维结构本身。

## 工作性闭合，而不是终极完备

当前六维是一种**工作性闭合**，不是关于现实“恰好只有六个基本维度”的证明。

框架对当前用途足够时可以暂时闭合；反例、预测失败、干预失败、结构张力、意外后果、长期特殊例外、失去可恢复性或更好的竞争框定都可以成为重新打开信号。

因此：

`当前六维有用 ≠ 现实恰好有六个终极维度`

`框架内部自洽 ≠ 框架与现实一致`

`局部形式验证通过 ≠ guide 已被证明为真`

竞争理论不需要先翻译成 guide 的词汇，才有资格通过现实后果、反例、预测或实践表现挑战当前框架。只有在整合、迁移或联邦协作时，才需要语义映射。

guide 不要求理论自行“退役”。理论不是行动主体；修订、缩界、替换、归档和停止使用都是有限系统围绕框架进行的活动。

## 使用评价

本框架不靠形式化证明建立自身的终极有效性。具体使用可以按与任务相关的指标评价，包括：

- 正确性；
- 可用性；
- 可靠性；
- 性能；
- 容量 / 可扩展性；
- 效率。

这些只是使用指标，不是新的理论维度。单一指标良好不自动建立整体充分性；当现实侧表现恶化时，应重新打开。
