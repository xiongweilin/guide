> 明确什么成立、为什么成立、谁可以行动，以及结果如何被确认。

这是一个关于人类活动中的区分、资格、价值、能力、变化、他者，以及知识、语义、制度和可靠行动的思想与方法索引。

本仓库把**世界**保留为认知边界：它指向不由当前观察、语言、模型和分类穷尽的现实，但不进一步断言世界本身最终由“差异”“关系”或任何当前概念构成。文档分析从人能够形成区分并参与活动之后开始，因此讨论的是**可区分世界中的人类活动**。个人、团队、组织、制度、Agent 和技术系统都可以成为具体分析对象，但任何一种对象都不是这套框架成立的前提。

## 基础边界

以下区分贯穿全部文档：

- **世界（认知边界）**：当前表示之外仍然存在什么，保持开放；不能从 Agent 的表示结构反推世界本身具有同样结构。
- **可区分世界**：在某种感知、语言、工具、交互和能力条件下，能够进入区分、比较、关系化和验证的现实侧面。
- **可区分范围**：在当前能力和接口下原则上可以形成的区分集合，包括尚未实际形成的候选区分。
- **已区分范围**：Agent 当前已经获得、形成并能调用的区分。它总是小于或等于可区分范围，并可能包含错误区分。
- **默认区分**：语言、文化、接口、历史决策或既有模型静默带入的分类和边界。默认存在不等于已经获得资格。
- **问题候选与问题资格**：一句话能够被提出，不等于它的问题结构已经成立。回答之前应检查对象、谓词、范围、前提、默认区分和预期答案类型是否足以支持当前问题。

## 人类活动的六个基础维度

仅有认知边界和 qualification 还不足以描述人类活动。对同一活动，至少需要同时保持六个不能静默替代的坐标：

| 维度 | 最小结构 | 核心问题 |
| --- | --- | --- |
| **区分** | `世界边界 → 可区分世界 / 范围 → 已区分范围` | 什么进入了当前世界，什么尚未进入？ |
| **资格** | `未满足 → 累积中 → 足够 → 进入` | 什么条件足以让候选或状态进入下一步？ |
| **价值** | `外界规范 ↔ 内在规范` | 什么值得、应当、被要求或被拒绝？ |
| **能力** | `不能 → 自身能 → 辅助能 → 借势能` | 哪些结果当前能够实现，以及借助什么实现？ |
| **变化** | `稳定 / 过渡 / 无稳定结构` | 当前面对的是持续结构、转换过程，还是尚无稳定结构？ |
| **他者** | `关联强度 × 一致 / 冲突` | 谁与谁相互影响，并在哪些维度一致或冲突？ |

六维不是六类对象，而是同一项活动的六个坐标。比如“能做到”不能推出“值得做”，“值得做”不能推出“有资格进入”，“当前稳定”也不能推出“长期有效”。

完整定义与交叉关系见[《人类活动的六个基础维度》](./six-dimensions-of-human-activity.zh-CN.md)。

因此，基础链条不是“现实差异直接产生判断”，而是：

`世界（认知边界） → 可区分世界 / 可区分范围 → 获取与已区分范围 → 概念、关系与结构 → 问题候选 → 问题资格 → 答案或模型候选 → 判断资格 → 决策、授权、行动与验证`

其中每一层都不能静默替代下一层；任何当前链条也不能被反过来当作世界本身的完整描述。

这些文档重点讨论不同层之间的边界：一个差异不会自动成为 qualification，一个判断不会自动成为 authorization，一次执行得到结果也不代表现实已经达到预期状态。

## 建议阅读顺序

建议先读六维总纲，再按上表顺序阅读。这样会先建立共同坐标，再从“差异如何取得资格”逐步进入“资格如何转化成精确行动和持久记录”。

如果更偏工程实践，可以先读[精确语义](./precise-semantics.zh-CN.md)和[行动、授权与可靠性](./action-authorization-and-reliability.zh-CN.md)，再回到知识、互动与制度这些基础内容。

## 关于本索引

本仓库是一组持续完善的概念、边界和判断框架。

只有在技术术语能够保留精确含义时才使用这些术语；读者不需要预先接受某一种特定理论体系。
