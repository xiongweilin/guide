> 一个从**外部现实中的最小自指**出发，再只增加形成有限行动、目的、局部充分性、行动、反馈与修订所需条件的工作框架。

guide 不给出世界的终极本体，也不把任何当前表示、模型、分类、六维、工程契约或实现当作现实本身。

## 最小结构

基础只从三个条件开始：

1. **外部约束**：存在不被当前表示穷尽、并持续约束当前表示的现实。
2. **反身区分**：进行区分的过程将自身与非自身现实区分开来。
3. **保持与再进入**：这一自身 / 非自身差异进入并保持于当前表示，并能够再次成为产生该差异的区分过程的区分对象。

这三个条件只足以形成 guide 所采用的最弱**最小自指**。它们本身不建立持续自我、自我模型、行动能力、目的、意识或规范性。

最小自指：

\`\`\`text
外部现实
   │
   │ 约束
   ▼
区分过程
   │
   ├──► 自身 / 非自身差异
   │             │
   │             ▼
   │          当前表示
   │             │
   └─────────────┘
          再进入
\`\`\`

只有继续增加条件，才得到 guide 的工作主体：

- **同一性连续** → 后续区分能够把自身一侧保持为同一持续过程；
- **受现实修订** → 已保持的自身相关内容可以被现实纠正，从而形成可错自我模型；
- **行动能力** → 某些可执行转换能够改变现实后续条件；
- **有限性** → 生命周期、感知、表示、计算、资源和控制能力受限；
- **目的性** → 某些后续状态、路径、约束或结果对行动具有不同意义。

到这里，guide 才使用**目的性有限行动者**这一工作主体。

当行动者既能继续取得区分，也能进入承诺性行动时，才出现局部充分性问题：

\`\`\`text
Reality ↔ 目的性有限行动者
                 │
              当前边界 B
                 │
        S(B, purpose, transition)
           ┌─────┴─────┐
           │           │
      不足 / 实质不确定  足够
           │           │
       探索 / 修订    选择 / 行动
           │           │
           └──────► 现实
                       │
                  效果 / 反馈
                       │
                保持 / 修订 /
                  重新打开
\`\`\`

上述顺序是框架中的条件依赖顺序，不表示所有现实系统都按这个顺序在时间中发展。

## 从最小结构到工作框架

- **基础层**：最小自指、连续性、可错自我模型、行动、有限性和目的性分别作为新增条件，不再静默打包进一个起始定义；
- **条件性推导**：充分性、探索 / 决策和重新打开还要求探索 / 承诺选择、纠错能力等附加条件；
- **工作性展开**：当前使用区分、关系、因果、时序、可能性、价值六个视角描述当前边界；六维不是不可约本体原语；
- **工程必要结构**：Decision / Authorization / Effect / Outcome、幂等、回读、恢复等只有在附加工程条件下才成为 correctness 必要区分，仍放在 \`engineering/\`。
