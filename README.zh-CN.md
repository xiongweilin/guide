# guide

[English](README.md) | [简体中文](README.zh-CN.md)

从**外部现实约束下的最小自指**出发，逐层添加条件的最小工作性推导。不提供世界的终极本体，也不假定任何当前表示能够穷尽现实。

## 起始条件

1. **外部约束**：存在不被当前表示穷尽、并持续约束当前表示的现实。
2. **反身区分**：进行区分的过程将自身与非自身现实区分开来。
3. **保持与再进入**：这一自身／非自身差异被保持于当前表示，并能够再次成为该区分过程的区分对象。

这三个条件只足以形成 guide 所采用的最弱**最小自指**；它们本身不能推出持续自我、行动能力、目的、意识或规范性。

## 条件依赖结构

```text
外部约束 + 反身区分 + 保持与再进入
    → 最小自指
    + 同一性连续 → 持续自身
    + 改变后续现实的行动能力 → 行动者
    + 生命周期与能力有界 → 有限行动者
    + 行动相关方向 → 目的性有限行动者

从持续自身出发的额外增强支路：
    + 现实侧可修订性 → 可纠错自我模型
    （不是成为行动者的必要前提）

继续添加条件：
    + 探索／承诺选择 → 局部充分性问题
    + 纠错要求 → 反馈修订／重新打开
    + 其他目的性有限行动者 → 多行动者互动
```

以上箭头表示**工作性的条件依赖**，不是现实中的时间演化顺序、普遍必要条件或数学同一。局部充分性不等于完整知识；多个行动者的存在也不自动产生治理权利或集体最优结果。

有限自主执行的两个工作性问题见[基本问题](basic-problems.zh-CN.md)。
