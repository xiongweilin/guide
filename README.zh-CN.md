> 明确我们区分了什么、什么足以成立、什么值得、什么能做、结构如何变化，以及人与人如何相互影响。

这是一个关于**人类活动基础结构及其工程表达**的思想与方法索引。

个人、家庭、团队、组织、制度、Agent 和技术系统都可以成为分析对象；Agent 只是“能够参与当前活动的主体”的一种形式化表达，不是这套框架成立的前提。

## 世界边界

本仓库把**世界**保留为认知边界。

当前观察、语言、模型、分类、schema、ontology 或知识图谱都不能因为可用，就被默认视为世界本身的完整结构。文档讨论的是**可区分世界中的人类活动**，不是世界本身的终极本体论。

至少保持：

- **世界（认知边界）**：当前表示之外仍然存在什么，保持开放；
- **可区分世界 / 可区分范围**：在当前感知、语言、工具、交互、能力和接口下原则上能够形成的区分；
- **已区分范围**：当前已经获得、形成并能调用的区分；
- **默认区分**：语言、文化、接口、制度、历史决定或既有模型静默带入的分类和边界。

因此：

`当前表示 ≠ 世界本身`

`未进入当前表示 ≠ 不存在 ≠ 不可能`

## 人类活动的六个基础维度

对同一项活动，至少同时保留六个不能静默替代的分析维度。它们不要求彼此独立、正交，也不要求处在同一逻辑层级：

| 维度 | 最小结构 | 核心问题 |
| --- | --- | --- |
| [**区分**](./theory/distinction.zh-CN.md) | `世界边界 → 可区分世界 / 范围 → 已区分范围` | 什么能够成为可区分内容，什么已经被区分，什么仍在当前表示之外？ |
| [**资格**](./theory/qualification.zh-CN.md) | `解释型 / 规定型` + `未满足 → 累积中 → 足够 → 进入` | 什么条件足以成立，以及这个“足够”是在解释中形成，还是按明确规则检查？ |
| [**价值**](./theory/value.zh-CN.md) | `外界规范 ↔ 内在规范` | 什么值得、应当、被要求或被拒绝？ |
| [**能力**](./theory/capability.zh-CN.md) | `未知 / 不能 / 能够` + `自身 / 辅助 / 借势` | 哪些结果当前能够实现、依据是什么，以及借助什么实现？ |
| [**变化**](./theory/change.zh-CN.md) | `稳定 / 过渡 / 无稳定结构` | 当前面对的是持续结构、转换过程，还是尚无稳定结构？ |
| [**他者**](./theory/others.zh-CN.md) | `关联强度 × 一致 / 冲突` | 谁与谁相互影响，并在哪些维度一致或冲突？ |

六维不是六类对象，也不是六条彼此独立的轴，而是同一活动中不能静默互相替代的分析维度。它们可以相互约束，并形成反馈关系。

六个维度在本框架中**同等基础**。任何一个维度都不是总维度，也不能取得对另外五个维度内容的定义权。区分问什么能够进入表示；资格问什么依据足以支持一次转换；价值问什么值得追求或拒绝；能力问什么当前能够实现以及借助什么实现；变化问什么能够保持、正在转换或需要重开；他者问多个参与者之间的关系、权力、承认、一致与冲突怎样改变活动。任何一个维度都可以约束、挑战或要求重新打开其他维度。

资格仍然是这六维之中的状态转换语义，而不是整个框架的高阶 owner。现实中至少存在两种形成张力的基本机制：**解释型资格**通过对语境和证据的可追责判断形成“足够”，**规定型资格**则按照已经明确的规则、谓词、阈值或 contract 检查“足够”。同一活动可以同时包含两者，但不能静默互相替代。区分与能力构成一类重要反馈：当前能力、工具、接口和他者限制什么能够进入可区分范围，而新形成的区分又可能揭示或创造新的可达路径；其他维度之间也可以形成自己的反馈关系。因此下面的阅读顺序只用于导航，不表示本体论推导、重要性排序或单向因果层级。

例如：

`能做到 ≠ 值得做到`

`值得做到 ≠ 已获得行动资格`

`当前稳定 ≠ 长期有效`

`我的区分 / 价值 / authority ≠ 他人的区分 / 价值 / recognition`

## 六维之间的 non-substitution

贯穿整个仓库的共同规则是：**一层成立不能静默替代另一层成立。**

典型边界包括：

`默认区分 ≠ 世界结构`

`能够提出问题 ≠ 问题已经成立`

`问题成立 ≠ 答案可靠`

`解释型资格 ≠ 规定型资格`

`规定规则已满足 ≠ 规则对当前对象适用 / 仍有效 / 有权约束`

`判断足够 ≠ 目标值得承诺`

`值得做 ≠ 有能力做`

`有能力做 ≠ 有权做`

`已授权 ≠ 已执行`

`执行成功 ≠ 现实效果已发生`

`现实效果发生 ≠ 目标已完成`

`历史有效 ≠ 当前仍有效`

这些边界在理论层由六维解释，在工程层由精确语义和 AIOS 继续保存。

## 框架完整性与自我挑战

本框架不把“完整”定义成“所有终极问题都已经有答案”。

更有用的标准是：

`未知没有被伪装成已知`

`缺失责任没有被静默替代`

`遇到边界时知道如何转交、重开或停止`

因此，能力实现仍然不完备，并不妨碍框架对“当前主张到哪里为止”保持相称责任。

框架自身也不免于这些规则。**guide 是一个可修订的工作框架，不是关于世界的真理来源。** 它的分类、区分、资格规则、价值 framing、能力模型、变化模型和对他者的表示都可能出错。现实侧 observation、反例、预测失败、行动失败、意外后果或更好的 framing，都可以要求当前主张缩界、修订、替换或退役。

一个竞争 framing 或理论，不需要先翻译成当前六维词汇，才有资格暴露当前框架的盲区或失效；只有在整合、federation 或 migration 时，才需要处理双方语义映射。内部自洽不能替代现实反馈。

当重要现实问题反复无法被现有维度定位或转交；当“保持开放 / unknown”长期不再产生新区分、新候选、有效缩界或有理由的停止；当维持体系需要不断增加特殊例外却没有相称收益；或者框架要求下游都可修订、自己却拒绝被审查时，都应重新打开核心结构。

因此默认维护循环是：

`使用 → 遭遇现实 / 反例 → 积累失败 → 必要时修订、缩界、替换或退役`

而不是持续扩大核心，也不是为了维护框架本身而维护框架。
