> 明确什么成立、为什么成立、谁可以行动，以及结果如何被确认。

这是一个关于知识、语义、互动、制度和可靠行动的思想与方法索引。

这些文档重点讨论不同层之间的边界：一个差异不会自动成为 qualification，一个判断不会自动成为 authorization，一次执行得到结果也不代表现实已经达到预期状态。

## 建议阅读顺序

按上表顺序阅读，会从“差异如何取得资格”逐步进入“资格如何转化成精确行动和持久记录”。

如果更偏工程实践，可以先读[精确语义](./precise-semantics.zh-CN.md)和[行动、授权与可靠性](./action-authorization-and-reliability.zh-CN.md)，再回到知识、互动与制度这些基础内容。

## 关于本索引

本仓库是一组持续完善的概念、边界和判断框架。

只有在技术术语能够保留精确含义时才使用这些术语；读者不需要预先接受某一种特定理论体系。
